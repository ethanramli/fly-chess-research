# Curriculum registrations

This is the output folder for the [curriculum campaign builder](../../.codebase/scripts/puzzle-learning/build-lichess-campaign-v1.mjs) and [parallel step builder](../../.codebase/scripts/puzzle-learning/build-lichess-parallel-steps-v2.mjs). They write the exact command, input hashes and resource settings that [the shared runner](../README.md) reads. The default full campaign registration, when generated, lives one level up at `python actions/curriculum-campaign.json`.

Earlier campaign registrations are in the [archive](../../archive/README.md#retired-python-actions). See the [current handoff](../../documentation/next-checkpoint.md) for the decision on further research.
