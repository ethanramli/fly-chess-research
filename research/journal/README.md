# Research journal

The journal preserves dated discussions, experiment notes, corrections, outreach records, and changes in direction. Start with the maintained indexes below; use [current research status](../../documentation/current-status.md) for the latest audited conclusions and [the decision log](../project/decision_log.md) for consequential decisions. Older landing-page material remains in [the historical landing-page record](https://github.com/ethanramli/fly-chess-research/blob/3262856e24edf3cda34bd3170a72ee88f8de4334/research/journal/README.md); any instructions or status statements there are historical, not current guidance.

<!-- directory-map -->
- [Archive](archive/README.md) — Superseded landing-page and instruction snapshots.
- [Discussions](discussions/README.md) — Researcher intent, hypotheses, scope decisions, and reflection.
- [Experiments](experiments/README.md) — Dated experiment notes, implementation corrections, results, and failures.
- [Outreach](outreach/README.md) — Historical expert discovery, contact, and meeting records.
