# 2026-10-07 capture-retention transfer assay v3

The frozen v3 protocol completed all 20 combinations of five declared model seeds and four feedback conditions. Each run began with scratch memory and replayed the same 16 independently checked one-ply capture-retention experiences. All run reports have atomic completion markers. The frozen aggregate reran each independent receipt auditor before calculating the preregistered gates.

Informative feedback selected the verified success on 5/8 final panels for every seed, the same panel accuracy as no-channel, shuffled, and disabled-plasticity controls. The predeclared pawn-relocation counterfactual failed for every seed: the action ranking did not switch when the blocker moved. Informative mean final margin was positive, but its paired mean margin was below each control. No registered transfer gate passed.

Receipts demonstrate persistent gain updates in the informative condition, but also in no-channel and shuffled conditions under the existing local rule. The disabled condition preserved scratch gains. Therefore a persistent gain change alone does not show that verified feedback improved choice. Repeat, reset, restoration, fixed-state, certificate, and recurrence checks passed.

The post-run seed-independence audit found exact equality of training activity, gain trajectories, held-out margins and choices across the five model seeds within each condition. The model seed randomizes input and output-head arrays, but the task adapter injects cues directly into KC cells with model input `[0]`, while the MBON readout reads neural activity directly and bypasses the output head. The run therefore contains one functional neural replica, not five independent initializations. The cross-seed bootstrap output is conditional descriptive uncertainty over the fixed system and eight final panels; it is not independent-seed evidence.

A second post-run check found that the scratch baseline already chose `a2a4` on all eight final panels for every seed-condition run. Training changed none of those choices. The apparent 5/8 accuracy is a fixed action bias, not learned success. Role scrambling altered candidate choices but still failed to make the correct counterfactual switch. The fixed MBON readout does not yet use this blocker relation to choose between the presented actions.

This is negative evidence for this specific interface, fixed readout, cue projection and one-pass schedule. It does not establish that transferable reasoning is impossible. The next design should identify a behaviorally effective source of replication or stochasticity and trace the specific blocker relation through input activity, local efficacy change and held-out action ranking before another long training run. The larger Monte Carlo puzzle-and-consequence-feedback objective remains unmet.

## Projection-map replication audit

The v3 protocol varied model seeds that the task adapter bypasses. A read-only static audit varied the cue-projection seed over eight values while retaining the frozen mapping and 14-cell/21-current dose. It reads train and validation only, verifies their hashes, and deliberately never opens final.jsonl. All eight projection variants produce distinct map identities; within-panel stimulation overlap ranges from2.0 to5.0 cells on training and1.5 to4.75 on validation. This is static input variation, not functional learning or independent neural initializations. The overlap metric is not a selection criterion. Future work must name these as projection-map factors, report them all, and create fresh untouched final families. ## Candidate-bound geometry prototype

The user reaffirmed the complete target: bounded Monte Carlo investigation, error diagnosis, verified consequence feedback tied to responsible choices, persistent neural adaptation, and improvement on unfamiliar positions under the same search budget. The current code has bounded search/review and a local replay receiver, but feedback still reduces to the selected board/action cue plus a scalar experimental valence channel; semantic explanation is not a neural input.

A concrete static diagnosis of the failed capture-retention transfer assay showed a distinct held-out blocker token sharing KC124 with an unrelated successful training token. I added a separate label-blind input prototype that binds the candidate target to aligned slider and intervening-piece geometry. It keeps the old model, graph, plasticity, readout and v3 source untouched. On train/validation only, relation inventories differ across12/12 panels; all24 cues select at least one relation-family KC and change their selected KC set versus v3, with the same14-cell/21-current dose. Mean direct within-panel KC overlap rises from3.25 to4.25 (train) and3.0 to4.0 (validation). This represents the relation structurally but establishes no neural activity, useful learning, credit assignment or transfer. The old final set was not opened by this audit and was already inspected in the earlier v3 assay.

Targeted cue tests and the full 138-test suite pass. No graph experiment ran. A new frozen comparison must use disjoint families, fresh final positions and matched controls, and must retain the larger Monte Carlo-feedback objective; this input prototype alone is not the learning bridge.
