# 2026-10-08: Lichess puzzle source and bounded curator

The researcher asked whether Lichess's existing puzzle collection can broaden the training pool. The official Open Database page reports CC0 licensing, a CSV schema with FEN/solution moves/rating/themes/source game URL, and Stockfish-based puzzle generation. It also defines the important move convention: FEN is before the opponent's setup move; the first listed move is that move and the second begins the solver's line. Lichess documents the solution-line player moves as “only moves,” except mate-in-one puzzles may have several mating moves. This is a useful teacher-search hint, while each row still lacks proof/alternative analysis required by our independent feedback gate. The official API specification describes the collection as public domain. Source/access details are registered in `research/literature/source-solution-register.md`.

Added `.codebase/scripts/data/curate-lichess-puzzles.mjs`, a Node-stream curator that consumes the compressed archive without loading it into memory. It verifies each listed line is legal from the supplied FEN, samples deterministically with a bounded reservoir, groups by source game for stable 80/10/10 train/validation/final assignment, drops duplicate sampled puzzle IDs/positions, and records source/tool/output hashes. Node 22.23.2 exposes the built-in Zstandard stream decompressor; no package was added.

This is only candidate-corpus preparation. The curator does not download source games, restore complete move history, prove omitted alternatives fail, certify the puzzle solution as uniquely best, or teach the graph. It marks history and consequences unresolved and labels all output ineligible for neural feedback. Any next experimental use still needs bounded independent consequence certificates, exact history binding, frozen family splits, matched informative/absent/shuffled/disabled conditions, retention checks and counterfactual transfer gates.

The official page also labels solution-line moves “only moves,” except where several mate-in-one moves win. This is useful to prioritize bounded teacher verification, but it is a source claim rather than an event-specific alternative-move certificate. The curator additionally checks the optional URL color and ply against the pre-setup FEN mover and move counter; the official examples were manually checked against these conventions.

Verification: `node --check` and `--help` passed. The official download is 293 MiB by HTTP HEAD. A sandbox download failed at its proxy; the approved retry resolved the host but transferred only32 KiB in about50 seconds (estimated more than5 days), so it was stopped and the incomplete file removed. No archive sample, full-PGN retrieval, certificate construction, learner exposure or resource measurement has occurred. Do not infer training-quality improvement from the larger source pool alone.

The official API offers `PuzzleAndGame` responses that include a game PGN and puzzle metadata/FEN; its batch route caps requests at50 and explicitly says not to enumerate puzzles for mass downloads. A single `nb=10` development request was attempted after approval but returned an empty reply, so no API sample was obtained. This remains a possible small-sample route when network service is available; the full corpus remains the database download.
