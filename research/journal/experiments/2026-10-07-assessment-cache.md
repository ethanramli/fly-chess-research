# 2026-10-07 assessment cache benchmark

Previous goal turn made progress: real Stockfish targets failed task-discrimination on inspected short-mate boards, changing the next teacher-design decision. This turn retains the full puzzle/verified-feedback/endogenous-memory/transfer objective while addressing the researcher's iteration-latency concern.

Existing profiles already isolate graph evocation as the largest cost. Added a bounded summary cache keyed by complete caller identity and board/history/task/ordered candidates. It stores no neural activity and never supplies replay rates. Frozen legacy sources remain untouched. All 119 tests pass, including invalidation after teaching, restoration/fixed-state changes and history/task separation.

Matched full-graph benchmark on one 32-candidate fixture: the uncached run used 129 presentations, 46.93 s wall time, and 24.23 s CPU time; the cached run used 65 presentations, 22.90 s wall time, and 11.89 s CPU time. The eight panels and two receipts/memories matched exactly, with one teaching invalidation. The independent audit passed 1,740 local recurrence checks and one certificate check. Both runs used the same 256 MiB heap, duty 0.5, and resource guards. This was one development workload in one order; it does not establish general training speed, time-to-learning, retention, or transfer. Fresh scientific repeat/reset/retention checks must bypass the cache.

Preserved v1 instrumentation failure: frozen encoder mutation rejected before panels or feedback. Separate v2 wrapper runs successfully. Follow-up: the v2 repeated-summary comparison alone was synthetic. A source-pinned [v4 root-search benchmark](../../../archive/early-development/research/reports/cached-root-search-v4-2026-10-07/README.md) tests reuse at an actual all-legal PUCT root after fresh repeatability panels. It saves 32 presentations and 10.10 s across the assessment and search sequence, while preserving the same policy, traces, and verified-failure choice. This is a result for one actual workload; broad training-time improvement and learning remain unproved.
