# Feedback evidence bound to the learner's decision

The researcher required informative feedback in every mainline learning experiment and asked for high-quality, consequence-linked teaching. The original puzzle, bounded investigation, verified consequence, endogenous learning and disjoint/counterfactual transfer objective remains unchanged.

Added `feedback-quality.mjs` and integrated it into the unfrozen bound-ray development runner. Before each scheduled teaching replay, the runner measures both candidate preferences with current memory. The evidence record binds position/history, task, memory fingerprint, scores, choice or tie, candidate coverage, reviewed action, and independently rechecked consequence. It distinguishes chosen-action review from alternative-action review. This fixed two-candidate schedule does not establish all-legal coverage or an adaptive error diagnosis.

Inspection found a material control bug before execution: the runner declared `no-channel` but its delivery branch checked `absent`, which would have delivered informative reinforcement to that control. The canonical condition helper now returns no channel for both verified valences under `no-channel`; the auditor independently checks the same condition. No graph run used this draft.

Four new tests cover chosen failure versus successful alternative, receipt snapshot isolation, stale memory, forged choice, changed history, nonfinite scores, incomplete certificates, incorrect outcome labels, ties, unknowns and channel controls. Full `npm test` passes 144/144. Both draft scripts pass syntax checks. Fresh pre-event assessments increase the planned per-condition count from 88 to 120 presentations; no protocol has yet been frozen.

The independent draft auditor now checks pre-feedback memory against the actual update's before-state, ranking arithmetic, candidate coverage, roles, context and certificate identity. Those checks validate recorded provenance and arithmetic; they do not independently reproduce the neural scores. Full graph replay, frozen source/dependency identities, complete protocol, matched runs and pending-receipt recovery validation remain required. No new neural training, learning or transfer result occurred in this work.
