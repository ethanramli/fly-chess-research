# 2026-10-09: Preregistered baseline-relative readout test

The v2 and adaptive-target v1 receipts suggested in a retrospective calculation that score change from each arm's own initial scores might reveal the selectively taught move even when the absolute MBON score still ranks a failure first. This reused the same puzzle and seeds; it is exploratory evidence and is vulnerable to overinterpretation. It does not show that the decoder generalizes or that the readout represents action value.

The narrowly stated hypothesis is: on a new model initialization, `delta(move) = final absolute score(move) - initial absolute score(move)` on the same FEN/action cue yields a unique all-legal maximum at certified Qh7 after informative feedback, while the absolute score remains led by the measured failure. Fully swapped feedback should remove/reverse the Qh7 delta advantage; absent and disabled conditions should have zero action deltas within `1e-12`. Both seeds 48 and 49 must match the prediction to count as replication support. No coefficients, labels, extra dose, or post-result thresholds may be fitted. The protocol explicitly treats same-position seed replication as the limit; it does not claim transfer or solve plasticity.

The v1 drafts initially failed to add the new hypothesis property because PowerShell's deserialized JSON object rejected assignment to an absent property. No run began and no draft was frozen. Explicit property insertion corrected both protocols; their model seeds, four conditions, hypothesis and predeclared gates were then checked. The first static-pin command also failed to parse because a PowerShell interpolated variable was followed by a colon; it ran no checks and was corrected with braced interpolation. The corrected preflight verified all source, graph, annotation, runner, auditor and seed pins. These preparation mistakes and corrections are preserved here.

The inherited runner records the same all-legal pre/post rankings and retains informative, swapped, absent and disabled controls. The inherited auditor rechecks feedback certificates, receipts, local updates and fixed model state before decoder analysis. Current process inspection found only the Codex resume process (not a graph run); available system memory was above the project's guard.

Seed 48 completed and the original pinned auditor failed before auditing because its JSON parser rejected the BOM written by PowerShell. That failed attempt is preserved at `research/reports/gamma2-relative-readout-2026-10-09/audit-bom-failure.txt`. A BOM-tolerant correction auditor passed: 152 frames replayed, direction and specificity gates passed, informative Qh7 was unique delta top, swapped Qg8 was delta top, and absent/disabled deltas were exactly zero. The absolute final choice remained Qg8. The pinned source and failed attempt remain intact.

Mistake discovered: changing `model.seed` from 47 to 48 did not create a new effective MBON-readout initialization. The seed changes input/head arrays, but assessment supplies `[0]` plus direct KC stimulation and reads MBON rates rather than the head output. All 208 initial/final move-score rows exactly match seed 47. Therefore seed 48 is a deterministic re-execution of the prior result, not independent replication; seed 49 was not run. The multi-seed replication gate is unresolved. The relative decoder can reveal the known same-position association in this deterministic fixture, but the experiment does not establish generalization or solve plasticity.
