# Volume 3: Reasoning

**Live integration evidence, 2026-11-01:** The [one-seed controlled pilot](../../../reports/long-term-memory-v1-live-comparison-2026-11-01/README.md) tested long-term-memory v1 during actual choices. On this trace, systems with memory made fewer wrong choices after the consequence changed, but all three informative systems ended with the same number of correct choices. The memory system made no more correct choices than the lookup-only system. On this pilot, adding the live neural score did not improve the result. That score still favored the action that had been correct before the change. The external memory overrode the neural score; the result does not show that the neural system learned the new consequence. This pilot supports the method, not unfamiliar-concept transfer or reasoning.

**Engineering evidence, 2026-11-01:** [Long-term-memory v1](../../../reports/engineered-episodic-memory-2026-11-01/README.md) is the researcher's name for a bounded memory component outside the connectome. It passed tests of exact-cue recall and selective revision on preserved development examples; a separate test reconstructed a scalar value. This gives the study a usable way to store information, but it does not show reasoning or transfer to unfamiliar concepts. The methods must say that this memory component can retrieve stored consequences. The study must compare it with a system that uses the same retrieval without the connectome.

## Researcher clarification, 2026-11-01

This volume tests whether a model based on the fly connectome can reason within set computing limits. The researcher defines reasoning as using several unrelated concepts to solve a problem the model has not seen before.

This study may use engineered memory and other computing aids if it clearly describes them. The engineered condition does not need a long-term-memory system that works like a fly's. Explain what each part does: the connectome, memory, memory lookup, move-selection rules and any search. State which parts can choose or rank moves. Test the full declared system, and use component controls to find out what the connectome itself contributes.

The current engineered-memory work provides a tool for testing reasoning in this volume. Test combinations that were kept separate from training, and paired cases where a changed consequence should change the best move. Compare the full system with lookup-only and no-memory controls to separate useful recall from applying concepts. Keep resource use bounded and describe every departure from fly biology. No result has yet established reasoning.

The separate study of biological memory limits belongs in Volume 4. It informs this volume but does not prevent testing the engineered system. See the [record of memory authorization and the candidate design](../../../reports/apl-locality-feasibility-2026-11-01/engineered-memory-scope-clarification.md).
