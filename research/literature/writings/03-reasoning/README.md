# Volume 3: Reasoning

**Live integration evidence, 2026-11-01:** [one-seed controlled pilot](../../../reports/long-term-memory-v1-live-comparison-2026-11-01/README.md) integrates long-term-memory v1 into actual choices. Memory-backed controllers make fewer wrong reversal choices on this trace, but all three informative systems finish equally correct. Matching lookup-only performance establishes no incremental live neural-score advantage; memory-backed neural scores themselves still prefer the old reversed action, demonstrating external override rather than neural consolidation. This is an enabling method result, not unfamiliar-concept transfer or reasoning.

**Engineering evidence, 2026-11-01:** [long-term-memory v1](../../../reports/engineered-episodic-memory-2026-11-01/README.md), the researcher-named bounded external episodic-memory component, passes exact-cue recall and selective revision on preserved development exposures, with a separate scalar reconstruction. This supplies a usable storage component, not reasoning or unfamiliar-concept transfer. Its direct consequence lookup belongs in the methods/disclosure and matched-controller baseline.

## Researcher clarification, 2026-11-01

This volume pushes the limits of biology and computer science to investigate whether a fly-connectome-derived model can reason under computational constraints. The researcher's operational meaning of reasoning is applying multiple unrelated concepts to solve an unfamiliar problem.

Engineered memory and other explicitly disclosed computational aids are permitted in this investigation. A biologically faithful long-term-memory mechanism is not a prerequisite for the engineered condition. Describe exactly what the connectome, memory, retrieval, policy and any search each contribute, including which components can select or rank actions. The tested subject is the declared complete computational system; component controls determine what can be attributed specifically to the connectome.

The present engineered-memory work belongs here as an enabling method for testing reasoning. Use disjoint unfamiliar combinations and changed-consequence counterfactuals, with matched lookup-only and no-memory controls, to distinguish useful recall from concept application. Preserve finite resource budgets and disclose all departures from biological mechanisms. No reasoning result has yet been established.

The separate investigation of biological memory limits remains relevant to Volume 4. It informs this volume without blocking its computational condition. [Recorded memory authorization and candidate](../../../reports/apl-locality-feasibility-2026-11-01/engineered-memory-scope-clarification.md).
