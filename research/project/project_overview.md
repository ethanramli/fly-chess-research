# Project overview

Lead researcher: Ethan Ramli, grade 11 student in Jakarta (self-reported). Primary framing: cognitive science with computational neuroscience and machine-learning methods. Target output: transparent empirical research report; publication venue remains to be selected.

The researcher asks whether a simple organism could reason. The project tests a computer model built from the released fruit-fly wiring map, starting without trained weights. Can experience change its connections so that it learns which chess choices lead to good or bad consequences? Can it use that learning on unfamiliar boards, and change its choice when a consequence changes? Success on these chess tests would not by itself establish reasoning across different subjects or chess understanding in a living fly.

The researcher ultimately wants the model to develop its own way of evaluating positions and playing chess, and reach 2000 Elo. Measuring that goal requires a named rating scale, reference opponents and a calibrated test. Early work uses puzzles and verified consequences with set computing limits to test prerequisites for learning. The broader question still requires unfamiliar-position tests. A later comparison with people could support a claim about relative performance.

The teacher supplies experiences and independently verified consequences; the model's declared learning mechanism determines how its stored state changes. Software translates boards into inputs and neural activity into move scores. Natural visual perception and the biological validity of these interfaces remain unresolved. See the [current research status](../../documentation/current-status.md) for the specific association tests and controls that passed. Useful puzzle learning and reasoning have not been established.
