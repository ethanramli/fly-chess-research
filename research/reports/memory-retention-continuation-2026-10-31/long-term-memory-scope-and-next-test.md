# Long-term memory is the prerequisite, not a later feature

2026-10-31. Researcher reaffirmed: keep the work on long-term memory because teaching cannot accumulate without it. This document governs the continuation's scope; it does not replace frozen protocols, select a rule, authorize graph activity or declare a pass.

## What would satisfy the goal

The mechanism must acquire an association, retain useful earlier associations while others are learned, retrieve them after explicitly modeled delays, survive an exact save/restore, and remain revisable when verified consequences change. These properties must hold together against absent, matched-shuffled and disabled-plasticity controls. Infrastructure, a retention-only pass, repeated immediate success or an immutable weight file is insufficient.

The [five-condition comparison](development-comparison-v2.json) remains a joint failure. All five main datasets passed separate event replay. No candidate is selected. The old full-grid failures and mathematically incompatible cells remain in the original package; the continuation tests one explicitly feasible development cell, not a repaired full-grid success. No biological retention timescale has been measured.

## What the focused research establishes

**Prediction feedback is a possible component, not the long-term-memory mechanism.** Bennett/Philippides/Nowotny2021, [primary full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC8105414/), DOI10.1038/s41467-021-22592-4, was re-read at Results Eqs2–6 and Discussion/model limitations. It treats acquisition and explicitly does not model consolidation. Its unrestricted rule uses cross-valence information; its within-trial timing is collapsed. Do not implement a teacher-calculated error scalar, add its proposed connections to the released graph, or call an acquisition result long-term memory.

**A consolidation-specific lead exists, with unresolved physiology.** Ichinose et al.2015, [primary publisher text](https://elifesciences.org/articles/10719), DOI10.7554/eLife.10719, was read at Results/Figure4 and Figures8–10 text/legends plus Discussion. Post-training disruption of the alpha1 circuit impaired later appetitive olfactory memory. PAM-alpha1 NMDA-receptor knockdown affected 24-hour memory without the same short-term effect. The proposed excitatory MBON-alpha1 feedback remained physiologically unresolved in that article. This motivates a post-learning causal test; it supplies neither calibrated visual-KC kinetics nor a revisable storage equation. Figures were read as text/legends, not visually inspected.

**Sleep is not a generic consolidation button.** Dag et al.2019, [primary publisher text](https://elifesciences.org/articles/42786), DOI10.7554/eLife.42786, was read at Results on DAN-aSP13 and vFB/dFB manipulations, Figures1/3–5 text/legends and Methods imaging-analysis scope. Courtship-memory consolidation depended on a particular post-learning reactivation pathway; sleep-promoting populations were not interchangeable. This does not justify replaying an answer table or applying its timing to visual chess inputs. No sleep circuit is implemented here.

## Static anatomical result and its limit

The [completed static check](feedback-path-feasibility-v1.json) reads 134209 released cells and 2700513 sparse edges, without neural activity or gain changes. It reports exact identities and direct DAN targets for 14 receiver cells. Appropriate-compartment example pools contain direct feedback for MBON05, MBON09, MBON07 and MBON06; the MBON27-to-PAM01 example has no direct edge. This does not exclude indirect feedback or establish a functional error signal.

In particular, the MBON07-to-PAM11 example contains 11 direct edges, all negative under the released fast-sign convention. The 2015 source's proposed NMDA-mediated excitation cannot be obtained by flipping those signs. A separate receptor-mediated component would need explicit evidence, location, kinetics and a declared approximation. The coarse released type names do not resolve every source subtype. Anatomical connectivity alone cannot select that implementation.

## Next decisive test: post-learning stabilization with delayed retrieval

This is a prospective design requirement, not a launch-ready or executed experiment. It adds a time/consolidation question without changing any original G1–G6 threshold or reinterpreting old results.

1. Specify a minimal local stabilization equation and its supported receptor/circuit trigger. Separate fast activity, eligibility, lasting efficacy and any stabilization state. Declare clock units, rates, bounds and the source-to-model mapping before code or results. A parameter frozen by construction is the storage control, not evidence for consolidation.
2. Use matched initial acquisition, then compare the complete mechanism with stabilization disabled only during the post-learning interval, at the same presentation/consequence count. Retain informative, absent, matched-shuffled and wholly disabled arms. A later, duration-matched intervention distinguishes early stabilization from general damage. No teacher-delivered signal or replay during quiet intervals; any endogenous activity must arise from the modeled circuit.
3. Pre-register delay values, neutral/distractor activity and interfering B/C learning before the new runs. Report quiet retention and retention under new learning separately. Store explicit simulated time and all dynamic state. Wall-clock waiting and CPU pacing never advance biological time. If the time mapping remains hypothetical, label results as a computational retention curve, not hours or days of fly memory.
4. Retest A unaided before any reminder feedback, check B/C acquisition, and run every original A-reversal test. Compare absolute margins as well as retention ratios so weak initial learning cannot look stable. Include exact uninterrupted-versus-restored trajectories at the same simulated times and recheck all verified feedback before replay. New delay-specific pass marks require a prospective, separate specification; do not back-fill thresholds after results.
5. Advance only a jointly successful candidate to the planned eye-route and real-model validation process. Fixture success remains software/computational evidence. Actual training retains the restart plan's memory-rule approval requirement. Chess teaching remains on hold.

The immediate research task is to resolve whether the source-supported alpha1 stabilization pathway can be represented without contradicting the released signs or inventing receptor kinetics. Prediction-sensitive acquisition remains a distinct candidate component and cannot substitute for that task. Other source-grounded memory mechanisms remain available if this pathway is unsupported; one unresolved path is not a reason to close the goal.
