## Cause and source policy

This is a conflict between annotation products on the **same v783 root-ID space**. The [v2.1 release](https://github.com/flyconnectome/flywire_annotations/releases/tag/v2.1.0) and its [column definitions at the pinned commit](https://raw.githubusercontent.com/flyconnectome/flywire_annotations/ebd66db2596fcc39c6950fb54ea3efa00f7fe8a0/supplemental_files/Supplemental_files_columns.md) explicitly identify v783 roots. A v630/v783 remapping is therefore not a supported explanation for these flags.

[Codex's documentation](https://codex.flywire.ai/faq) explains that it consolidates types from multiple publications and that downloadable products can differ from publication-time archives. This explains why a shared snapshot identifier alone does not guarantee identical annotations; it does not adjudicate these particular neurons. Codex primary types, classification and column files must not be counted as three independent biological validations.

For interpreting the existing frozen Eyes v1 artifact, keep the sources explicit:

- **Stored retina type:** the Codex primary type used by the original builder; source hash `8aba246d71dc40361677493629972ce3883048c3d02010adc42bda22962a1a2d`.
- **Eye/column placement:** the pinned Codex classification and column tables, with graph-stored coordinates. Result hashes identify their exact bytes; upstream graph metadata records matching file sizes but not source-file hashes.
- **Alternate type and curated transmitter:** retain the v2.1 TSV values separately, with its existing hash. Neither curated transmitter nor predicted transmitter supplies a replacement cell type or a universal synaptic sign.

This corrects the interpretation of the annotation manifest, not neuron selection. Keep all thirty-eight disagreements visible; no automatic removal, relabeling, sign change or global replacement of annotation sources is justified. Physiology, morphology or source-level adjudication is still needed for a biological claim. A future color benchmark must account for the subtype disagreements and specify spectral drive; the current renderer applies scalar picture intensity to every selected type.
