2026-10-12. **Exploratory static schedule analysis only.** This does not replay neural activity, train a learner, change the frozen G0 gate, or explain the reversal outcome.

The archived G0 schedule generator and protocol from `runs/curriculum-g0-assay-v1-resumed5` were used. The recreated frozen schedule hash matches protocol hash `c5543dd8f91ed3a004b80539d54d1dc138f93ff9b7aef1d7345702d9aef8e`. For each reversal cue, the analysis counts how many of its four shuffled labels (two actions, twice each) match the true reversed contingency. It also counts target-cue labels across acquisition plus reversal against the eventual reversal truth, since arm memory carries across those phases. The separate interference cues are excluded from that target-cue count. The frozen shuffle seed is compared with deterministic seeds0-511. This is a bounded exploratory sensitivity sample, not a preregistered inferential sample.

They count assigned labels only, not neural updates or their effects.
