# Words used in these reports

**Fly** means the simulated fly in this project. It does not mean a living fly.

**Eye input** means the signals the simulated eyes send to the fly after code converts a chess board into values.

**Fly memory** means saved values inside the simulation that can change after training and affect later move scores.

**Training** means giving the simulated fly examples and feedback so its saved memory can change.

**Teacher** means the program or person that supplies the answer used to train the fly. The teacher is outside the fly.

**Result checker** means the separate program that checks whether saved answers and results meet the stated rules.

**Exact-match answer file** means a separate file that returns a stored answer only when the new input is exactly the same as a stored input.

**Transfer** means using what the fly learned on a chess position it did not see during training.

**Connection multiplier** means a number that scales how much one simulated brain connection affects its next cell. The eye-test plan uses 1.8; the inspected learning rule allows at most 1.

**SHA256 code** means a calculated value used to check whether two files or sets of values are identical. It does not prove that the information is correct.

**En passant** is a pawn capture that is allowed only immediately after an opposing pawn moves two squares. The capturing pawn moves to a different square from the pawn it captures.

**MBON05** is the project label for mushroom body output neuron type 05. The mushroom body is part of the fly's learning circuit.

**Kenyon cells** are cells in the fly's mushroom body.

**Required score** means the minimum result a test must reach to count as a pass.
