## Proposed direction in plain language

Find a memory mechanism that learns B without destroying useful A, recalls both after modeled delay and distracting learning, and can change A when its verified consequence changes while leaving B useful. Investigate three interacting requirements: sufficiently distinguishable inputs, appropriately selective synaptic changes, and lasting but revisable storage. A slow weight or a protected synapse alone does not establish this combination.

The starting candidate is the project's existing proposal for **local control of plasticity on verified visual KC-to-MBON synapses**, followed, only if justified, by a source-supported revisable stabilization mechanism. The strongest specific local-protection lead in the existing notes is mAChR-B-mediated lateral modulation; APL/local inhibition is a separate representation lead. Orb2-associated stabilization and interacting fast/slow states are storage leads to evaluate, not components already selected for installation. Their relevance to these visual compartments and their capacity for reversal remain unverified.

This starting point restores the [October 30 recommendation](../../literature/memory-interference-2026-10-30/recommendation-and-test-plan.md), rather than claiming that the project had no ideas. The current local-gated and reservoir families already implement some eligibility/hidden-state concepts and have preserved failures. Repeating those mechanisms under a new name is not a new proposal.

## What the next research phase must deliver

A primary-source evidence matrix with exact read coverage; a released-cell/receptor/compartment crosswalk; a comparison of the local-modulation, representation and stabilization candidates; one recommended mechanism or an explicit no-go; supported equations separated from introduced approximations; a bounded preregistration-ready test proposal with resources, controls and rejection rules. Numerical rates or a biological clock must not be invented to fill source gaps.

The scope is a computational prerequisite for later consequence-sensitive chess transfer. A memory assay does not establish reasoning, and model-time persistence does not establish hours or days of memory in a fly.
