# Stockfish mate-deadline score diagnostic v1

Completed 2026-10-07 by retrospective analysis of the hash-bound, independently audited Stockfish target-feasibility records. The reproducible analysis is [analysis.json](analysis.json), generated by [analyze-stockfish-mate-deadline.mjs](../../../.codebase/scripts/puzzle-learning/analyze-stockfish-mate-deadline.mjs). It rechecks the source report/audit completion hashes and every raw record hash before summarizing.

The full-game WDL target tied several deadline failures with the verified success. Exact UCI mate scores contain one narrower signal: in each of four board/budget panels, the sole certified success (`c4g8` or `b3g8`) had actor-relative mate score `+1`, while the one failure with an exact mate score (`h6f7`) had `+3`. Thus the recorded mate distance distinguishes those two target types where WDL saturated.

This does **not** produce a complete all-legal target. Of 124 candidate records, 82 had usable exact latest scores and 42 were unavailable. Among the 82, only four successes and four failures had exact mate scores; 74 failures had centipawn scores. Mate distance and centipawn values cannot be merged into a calibrated common scale using this evidence. The diagnostic did not send neural feedback, alter memory, or test training speed, acquisition, or transfer.

## Decision

Stockfish remains a plausible source of task-aware teaching information, but this dataset only supports testing a sparse exact-mate/deadline signal. Before a graph condition, define a fixed output and mapping through the existing teaching pathway, retain unknown handling, and compare against verified-consequence, absent, shuffled, and disabled-plasticity controls. A successful all-legal learning result and disjoint/counterfactual transfer are still required to claim movement toward reasoning.

## Provenance

The source records come from the [Stockfish target-feasibility report](../stockfish-target-feasibility-v1-2026-10-07/README.md), whose independent certificate and perspective audit passed 124 records. The analysis is retrospective; the two boards are inspected development/training positions and are not transfer evidence. This artifact adds no external biological or Stockfish claim beyond the already registered Stockfish score semantics.
