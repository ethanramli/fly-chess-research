## Strongest alternative explanations retained

For low-overlap failures, the numerical rule, graded/shared credit, limited own-choice exploration and fixed exposures remain possible causes. The self-limit intervention tested one specified alternative, not all prediction-error learning. Both slow settings used the same one-way approximation, so they cannot falsify all slow storage or Benna/Fusi's coupled model. A successful alternative representation could evade the static bound, but no such representation was implemented or shown biologically justified.

The fixed readout bound concerns a single shared state at T3: it is valid because value reads are pure and the assay does not condition gains on the test item. It gives the candidate more freedom by allowing all independent edge differences in a generous Float32-expanded box. Additional hidden states that still produce only those same magnitudes cannot increase this bound. Item-conditioned retrieval or a nonlinear recurrent readout would be a different architecture. It is not a proof of input identity or universal incapacity.
