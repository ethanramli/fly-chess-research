# Capture-retention assay v3

The frozen 20-run comparison completed under protocol [v3](../../data/capture-retention-transfer-assay-v3/protocol.json), SHA-256 `abb80b8c33e7e0204b8bb141fcfa3f23f81dcce6a546622bdebca054fdf2f279`. The source archive is [preserved here](../../source-archives/capture-retention-transfer-assay-v3-frozen/). Each of five declared seeds ran informative, no-channel, shuffled and disabled-plasticity conditions from scratch. All 20 runs have atomic reports, completion markers, 16 checked teaching receipts and an independent receipt/certificate/recurrence audit embedded in [aggregate.json](aggregate.json). The aggregate SHA-256 is `33c6edf9d8b7ce4c5cd07e5e023fd3d18ab21b9b7706d34e188071142f2de479`.

Informative feedback selected the certified success on **5/8 final panels for every seed**. Every control also selected 5/8. A further audit found the key shortcut: **before training, every seed-condition run already chose `a2a4` on all eight final panels; no training condition changed any final choice.** The 5/8 is a baseline action bias, not learned success. On the counterfactual pair, the intact readout preferred `a2a4` to `e2e6` in both positions: by `0.007583` on `te-01` and `0.006381` on `te-05`, even though the correct action reverses. The fly chose `a2a4` in both, rather than switching to `e2e6` on `te-05`. Role-scrambled input did alter choices, but did not solve the pair. Informative mean final margin was `+0.0014369`, but its paired margin difference was negative against no-channel (`-0.0006754`), shuffled (`-0.0017092`) and disabled (`-0.0006544`). The registered transfer gates fail.

Memory gains changed under informative, no-channel and shuffled plasticity-enabled conditions, but disabled memory stayed fixed. These changes did not improve the held-out choice ranking: the strongest mean margin belonged to shuffled feedback, and the candidate choice remained wrong on the counterfactual. Exact repeat, reset and restoration checks passed. The audit independently checked 320 consequence certificates and 208,800 enabled local gain recurrences.

The nominal five model seeds are not five functional replications. The [seed-independence audit](seed-independence-audit-v3.json), SHA-256 `9ef423658657fe053ff151357db23eb7bed7f49840399c6f671a673121c97768`, confirms identical training activity, gain trajectories, margins and choices across seeds within each condition. It also verifies the baseline and trained choice policy match exactly in all 20 runs. Source inspection explains why: the seed randomizes input/head arrays, while this task injects stimulation directly with a zero-valued model input and reads MBON activity without using the model head. Treat the bootstrap interval as conditional descriptive uncertainty over these eight panels, not evidence replicated across independent neural initializations.

This is a failed narrow consequence-transfer assay, not evidence that transferable reasoning is impossible. It contains no Monte Carlo search, multi-ply reasoning, or calibrated Elo evaluation. The next design must establish behaviorally distinct, appropriately matched replication before using seed-level uncertainty; it must also explain how a changed blocker relation can alter candidate ranking through the existing local memory and fixed MBON readout. Preserve v3 and all failures unchanged.

## Read-only localization of the blocker path

An exact neural replay of the frozen scratch and informative-trained checkpoint reproduces the saved candidate scores without changing memory. The moved-blocker candidate `te-05/e2e6` is active at KC124 (excess rate about1.482). The same KC was active during training event `tr-07/e1e5` for the distinct token `around-target:r:self:p:2,-3`, which received verified success/PAM02 feedback. Its KC124-to-MBON12-right edge ended at gain0.9986641 (scratch1.0; it was0.997327 at the event13 checkpoint before later recovery). The held-out candidate's `a2a4 - e2e6` score gap narrowed from about0.007749 at scratch to0.006381 after training, but remained positive, so the required choice switch did not occur.

This is a concrete shared-code collision and a plausible interference route, not an isolated causal explanation. Other tokens and recurrent activity also contribute to the margin. The feature-alias audit is [feature-alias-audit.json](feature-alias-audit.json), SHA-256 `4ec84d4991d673a8ae4aab3cc45919f925e5015db55769435ae3e8496f66f5d9`; the exact replay is [counterfactual-activity-probe-v3.json](counterfactual-activity-probe-v3.json), SHA-256 `97927bacc535d3e772e5a2e6e82195d9d8471c0ede510d1c5ebcb353f7d7e080`. Both are post-run diagnostics against the already inspected v3 counterfactual, not untouched final evidence. They support a pre-registered projection/readout diagnosis with fresh held-out families; they do not justify claiming reasoning or starting another repetition-only run.

## Projection-seed audit

The v3 protocol varied nominal model seeds while holding the cue-projection seed fixed. A static follow-up varied the **cue projection seed** across eight declared values and read only the training and validation families. All variants retained14 stimulated cells and dose21, but produced different KC assignments: mean candidate-pair overlap ranged from2.0 to5.0 cells on training and1.5 to4.75 on validation. None had identical cue patterns within a panel. The original seed14009 is only one fixed map; changing the model seed in v3 did not create functional neural replications.

The [projection-seed audit](projection-seed-audit.json), SHA-256 `0314c69436c6024d3b6bf36f539de8f034aa4f299a5af68d69470b9f62242981`, deliberately does not open the final split or run the graph. These are engineered input-map variants, not neural initializations and not learning evidence. Do not pick the lowest-overlap map using these exploratory summaries. A future frozen assay should either hold one projection fixed and make a single-system claim, or treat predeclared projection maps as a design factor with fresh final families and report every map.

## Bound-ray input prototype

A separate label-blind cue prototype binds the candidate target to aligned slider geometry and to each intervening piece. It retains the14-cell/21-current dose and leaves the graph, local plasticity, readout and teacher unchanged. The static audit [bound-ray-input-audit.json](bound-ray-input-audit.json), SHA-256 `14b86a883a25b9eebd1cd8299f0bfe6147f13d86c171d9dc68e2024b6cf592bc`, covers only the eight training and four validation panels. All12 panels have different relation-token inventories across their two candidate moves; all24 cues select at least one bound-relation KC and have a different selected KC set from v3. All36 relation tokens in these inputs survive projection. Mean within-panel stimulation overlap rises from3.25 to4.25 cells on training and3.0 to4.0 on validation. The relation is represented in the input; no neural activity, learning, causal credit, or better choice is established. The already inspected final family was not opened.

This is a testable input hypothesis, not a repair selected from final outcomes. See the [design contract](../../../documentation/design/chess-input/bound-ray-relational-cue.md). A future graph comparison needs a new frozen disjoint family/protocol and matched feedback controls. The full Monte Carlo investigation-to-verified-feedback-to-transfer goal remains unmet.
