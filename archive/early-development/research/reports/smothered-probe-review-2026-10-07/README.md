## Checks that support the design

[ReversalMemory](../../../.codebase/src/neural-learning/reversal-memory.mjs) initializes gains to one and events to zero. The probe snapshots this state and restores it before each variant; restoration reapplies the base magnitudes. [SparseTrainer.forward](../../../.codebase/src/supervised-baselines/trainer.mjs) clears initial neural state and computes subsequent activations afresh, so model reuse does not carry the previous variant's activity forward. A new brain also resets the presentation counter. The fixed-state hash is checked before comparison and after each replay, protecting graph/nonplastic parameters while intentionally excluding permitted plastic magnitudes. Readout and DAN root identities are checked against released IDs. The memory constructor validates existing positive edges and their KC endpoints; this does not independently revalidate every anatomical annotation or mapping derivation.

[DualValencePuzzleBrain.replay](../../../.codebase/src/puzzle-learning/dual-valence-puzzle-brain.mjs) reconstructs and verifies the board/action proof before neural feedback. Unknown experience is not rewarded. The pinned selected experience is required to be successful `c4g8`. Its receipt contains before/after memory, local rates and update information; the teacher does not calculate the efficacy update.
