# Retention event localization V1

[Frozen protocol](protocol.json) compares exact saved memories before the second puzzle's feedback, after its punishment and after its reward. These are learned intermediate snapshots, not artificial hybrids. The original trained c4/f8 board is evaluated over all legal moves with feedback disabled and memory unchanged.

Protocol SHA256: `f098372db0fe789b8597220039b2adce7c50c9ec7cca4f35775a45813e933888`. Sources are archived in `research/source-archives/retention-event-localization-v1-frozen`. [Audit protocol](audit-protocol.json) pins the separate artifact/certificate auditor. [Results](../../reports/retention-event-localization-v1-2026-10-07/README.md).

This localizes decision-boundary loss to an event in one development sequence. It cannot distinguish depression from recovery within that event, establish biological timing, or establish unfamiliar transfer.
