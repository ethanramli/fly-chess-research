Earlier bad choices return during later teaching. A sampled ranking prefix and numerical recovery decomposition observe this together, but earlier causal interventions generally failed to prevent revival.

Distinguish: (a) recovery overwrites useful earlier corrections; (b) directly overlapping or propagated cue activity depresses useful action representations; (c) fixed MBON comparison ranks a different bad action highest even after successful local correction; (d) delayed contexts lack an operative timing/omission pathway. Multiple explanations may contribute.

## Fushiki's shared-signal comparison

The existing punishment-only control does not compare separate versus shared dopamine modulation. For a fresh association protocol, hold actual neuron identities, wiring, KC cues, delivered events, persistent per-edge memory, dose, numerical pacing and readout fixed. Compare the existing group-local factor with a pooled factor used across the same eligible groups.

One possible engineering ablation is an edge-count-weighted mean factor. This matches total edge-weighted modulatory drive before activity interaction and clipping; it does not match resulting gain changes or biological dopamine release. Keep every DAN's raw activity, use disjoint controls and record this confound. Collapsing all memories into one scalar per neuron would change a second factor and cannot isolate signal diversity. This proposed ablation is not a natural physiological mechanism.

Freeze seed count, equivalence tolerances, acquisition/retention/reversal gates and absent, balanced nondegenerate shuffled and disabled-plasticity controls before launch. Use identical exposed experiences. Separate-channel superiority in one task would show a dependence of this implementation under these bounds, not universal necessity in flies. Current successful association results have not performed this comparison.

2. Recover complete equations and independently measured timing predictions; the retrieved HTML loses mathematical notation. Specify local KC/DAN eligibility state and modeled time, numerical integration and scope. Equal endpoint activity with reversed cue/feedback order must yield a testable prediction where the source supports one. CPU pauses do not supply this time model.
3. Test cue only, DAN only, paired/unpaired, opposite order, unrelated cues and omission after a learned expectation. True modeled omission is a known absence of an expected consequence; exhausted chess verification is unknown and supplies no event. The teacher must not calculate an omission prediction error or neural delta.
4. Keep persistent efficacy separate from bounded transient traces, compartment release/receptor assumptions and neural activity. Pin all identities; publish memory/traces plus pending receipt atomically before acknowledgement. Resume after feedback and before acknowledgement without duplicate updates; serialize checkpoint timing/history context as required.

Float64 storage is 6,960 bytes per trace across the currently mapped 870 edges, excluding metadata and larger runtime arrays; actual RSS must be measured before resource claims. Preserve 768 MiB RSS, 256 MiB free-memory, heap256 and duty0.5 guards.
6. Freeze fresh association, retention and reversal tests and physiological predictions before fresh training-only chess experiments. Checkpoint selection uses disjoint validation families and per-criterion gates. Freeze final tests; inspected fixtures and symmetry copies are not fresh final transfer evidence.
