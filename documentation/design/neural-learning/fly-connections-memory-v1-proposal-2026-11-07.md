## 1. Limits first

This is a proposed connectome-constrained computational hypothesis, not a faithful living fly, measured receptor model or biological memory lifetime. APL spatial physiology does not establish an anti-overwrite mechanism. The retained contacts use midpoint/skeleton projection with known branch ambiguity. The learning equation is a published theoretical rule adapted to released fly edges; the original full incentive circuit is not replicated. Fixed numerical rate steps do not represent seconds. A negative MBON05 preference score is an explicit engineering decoder, not a settled behavioral-valence or transmitter claim. These limitations cannot be removed by a gate pass.

The question for review is whether this condition is sufficiently source-constrained to test P1-P3 honestly. Reject building if an indispensable biological fact is missing. Do not turn a source-motivated computational pass into biological validation. If the primary condition can support only an engineering claim, state explicitly that it cannot complete this goal under its present wording.

## 2. Named mechanism and prediction

**One stabilising intervention:** contact-local APL inhibition, motivated by [Amin et al. 2020](https://elifesciences.org/articles/56954), with the existing dopamine-driven KC-to-MBON gain rule from [Gkanias et al. 2022, equation 1](https://elifesciences.org/articles/75611). No slow reservoir, biochemical tag, protected item mask, episodic store or new synaptic contact is added.

Prediction (hypothesis): local APL feedback changes KC co-activation and may reduce harmful overlapping updates while retaining useful distinctions. The source does not guarantee this prediction: Amin's Appendix 1 actually favors all-to-all over self-inhibition for decorrelation. A failure is informative; lower activity alone is not a benefit. The source's spatial constant is not a temporal constant or a fitted parameter for this specimen.

Start evidence: [next-mechanism decision](../../../research/reports/memory-interference-diagnosis-2026-11-01/next-mechanism-decision.md), [completed geometry work](../../../research/reports/apl-locality-feasibility-2026-11-01/README.md), and [computational bypass condition](../../../research/reports/apl-locality-feasibility-2026-11-01/computational-bypass-spec.md). Live publisher access on 2026-11-07 verified Amin's connectome-analysis equations and Discussion/Appendix caveats and Gkanias's equation 1; this is targeted text coverage, not full-paper or figure inspection. Cached primary texts/XML and source pins remain the raw evidence base. Add the exact adaptation to the source-to-solution register before experimental use.

## 3. Local APL calculation (new isolated component)

Use existing APL roots `720575940613583001` (right) and `720575940624547622` (left), the two pinned v783 skeletons and **every** retained KC/APL contact (215,419; 10,343 ordered pairs). Reconcile roots, signs, pair totals, contact directions, units and file hashes before building an input package. Missing or unmatched contacts fail preflight; do not discard outliers.

Subdivide each skeleton edge at projected contacts. This adds numerical sites inside APL, not new fly neurons or graph connections. Evaluate `K(x,y)=exp(-d_tree(x,y)/L)` by the existing linear-memory two-pass tree kernel. Primary `L=50,000 nm`, a declared transplant of a published fitted scale rather than a fit to this fly. Keep uniform-radius geometry; do not invent missing radii. No dense all-pair matrix.

For each numerical rate step, distribute each existing KC-to-APL aggregate magnitude evenly over that ordered pair's contacts. At each APL output contact y, sum these weighted KC inputs through K. Add the original APL's bias/external input and all its non-KC recurrent inputs as a common drive. Apply the original APL cell's saturation and leak to a separate **transient** state at y. For each existing APL-to-KC edge, replace its scalar APL contribution with the mean local contact state for that pair, multiplied by the original fixed signed magnitude. Remove the original scalar contribution once; never add both. Non-KC outputs of APL retain the original scalar state. All other graph dynamics remain unchanged.

With K=1 (infinite length), local states must equal the original scalar APL state to numerical tolerance on independent small fixtures. This supplies the mechanism-disabled comparison and detects double counting. Common non-KC drive, equal-per-contact weighting, the transplant to FlyWire and numerical leak are explicit approximations, not measured local physiology. Candidate observation resets **all** transient APL states; none stores a lesson.

Geometry sensitivity, predeclared without teacher labels: primary midpoint projection; an alternative using the known APL-side projection for all 126 canonical sample records and primary projections elsewhere; and an alternative using the second closest geometrically distinct segment whenever its residual is within 100 nm of the best residual (otherwise the primary segment). Compute ties in segment-ID order. Report every switched contact. The last alternative is a stress test, not an anatomical bound. No task-dependent branch selection or dropping contacts. The primary is fixed; a successful sensitivity arm cannot replace a failed primary. Report P1-P3 separately for each geometry. Joint biological robustness is not claimed from this finite range.

## 4. Lasting state and teaching pathway

Primary persistent state: one bounded gain on each retained positive gamma-KC-to-MBON05 edge on its correctly mapped receiving side. Stream the pinned annotations and save every KC/MBON/PAM root/index/side/type and the mask. PAM08 must be identified as gamma4 from the pinned ontology/source crosswalk. Do not broaden the mask to other compartments to obtain a pass. Preserve graph topology, signs, and every other parameter. Use the released graph, including its known MBON05 sign uncertainty, unchanged.

Candidate gain update: `g_next=clip(g + eta*D*(k + g - 1), 0.2, 1.8)`, `eta=0.5`, `k=max(0,cueKC-restKC)/1.5`. This is the existing Gkanias-derived rule; it is not a new protected-memory equation. The allowed D is always <=0. The teacher never supplies parameter deltas, negative dopamine, an edge mask or an association identity. No update on omission; source-derived recovery of inactive depressed edges may occur during a delivered pulse and must be counted as potential overwrite.

**Repair to the v1 sensory-DAN confound:** for each scheduled experience, read the cue-only neural endpoint from the unchanged current snapshot. Record cue KC eligibility and cue-only PAM08 rates. For a positive verified teaching event, replay the identical cue with a +0.75 experimental current to the mapped PAM08 neurons, from the same transient starting state. Let `D=-mean(max(0,taughtDAN-cueOnlyDAN))/1.5`. Use the previously recorded cue KC eligibility, not a teacher-computed KC target or the KC response contaminated by the teaching pulse. This is an explicitly paired direct-stimulation measurement of the delivered pathway's response. The counterfactual subtraction and quasi-steady pulse timing are engineering approximations. They isolate externally evoked teaching from endogenous sensory dopamine; they are not claims that the fly naturally subtracts two trials. Reject source suitability if that subtraction makes the primary claim untenable. Save both neural endpoints and the rule inputs for independent replay.

For a negative/zero criterion event, the certified absence of the positive pulse yields D=0; there is no invented aversive mapping or signed reward-omission law. Unknown verification yields no event. The absent arm never delivers a pulse. The disabled arm delivers the informative pulses but changes no persistent parameter. A shuffled arm permutes the same verified positive/zero event list within each A/B block with a fixed seeded permutation. This tests the information in timing, not unequal reward counts. A mechanistically active no-pulse sensory response must not be called dopamine absence.

Before using this with chess, dry-run fixtures must demonstrate acquisition from a naive state, retention under subsequent informative updates and error repair against absent, shuffled and disabled controls. Historical gamma4 failures remain failures. No freeze of learned edges is permitted.

## 5. Chess experiences and candidate choices

Reuse Eyes v2 unchanged (including the disclosed captured-piece image), source-game replay, legal enumeration, certificate generation/rechecking and s/c tie scoring. Read the search/feedback and puzzle-learning navigation before modifying any of their code. The fly receives only its rendered candidate board and the declared teaching intervention. It receives no safety flag, task answer, certificate, piece-value feature or filtered move list.

Criterion, fixed before data: select a legal **non-king capture whose mover cannot legally be recaptured on the landing square on the opponent's next ply**. Success has exactly that one-ply scope. Every legal move, including king moves and quiet moves, is ranked. A quiet or king move does not meet this narrow capture criterion; it is not described as unsafe or losing. Unsafe captures have complete one-reply legal recapture certificates. Resource-exhausted proof is unknown, never an unsafe label. King and quiet legal actions need independently replayed legal/noncapture/king task-membership certificates, rather than fabricated recapture proofs. The teacher's total legal-action domain is separate from the scored successes.

Score is fixed to minus the mean raw MBON05 endpoint rate, with no fitted head or chess heuristic. Complete persistent state and board/history identities must match before/after every candidate list and permutation replay. Use zero transient neural state for every candidate. All legal moves sorted lexicographically by UCI. Top ties use `abs(diff)<=1e-9+1e-7*max(abs(scores))`; report chance of success as s/c among all tied top moves. No move sampling or safety-dependent pruning. Store the full score list before any feedback.

The externally scheduled experience tape includes every legal move on every practice board in fixed UCI order, once per epoch, for 4 epochs. All arms receive the same boards, candidates, order and cue/teaching observation counts; absent/disabled observations use no teaching where required but matching forward-pass budgets. This is a fixed-experience assay, not self-directed exploration. No control is credited as mainline learning progress. A cue-only read and an optional pulse read must not become two learning events.

## 6. Data separation and capacities

Development uses existing source games 1-600 only, with game-level A/B membership fixed by the source selection order: 1-300 A, 301-600 B. Pick the first 32 eligible unique boards per group in preserved generator order, with at most one board per game. Eligibility means legal replay is complete and the board has both a certified safe non-king capture and an unsafe non-king capture. Disclose this enriched benchmark selection prominently; candidate lists still contain all legal moves. No seed uses different examples. Development seeds 7101/7102/7103; each runs all arms, with no selection of a favorable seed. No grid search: the fixed first version is accepted/rejected jointly.

Full confirmation needs a **newly acquired, excluded-game-checked** source partition that no previous practice or evaluation has used. Register exact selected game IDs, source hashes, PGN replays, board exclusions, A/B group membership, sample counts, code pins and seeds before neural use. Minimum 32 practice boards each for A and B, 32 unseen test games each for A and B; the new test data must not be opened for tuning or selection. Only the source/teacher auditor sees sealed labels before the fixed evaluator. A missing data package is a launch block, not permission to reuse v8's observed test result as sealed confirmation. Full seeds 7201/7202/7203. No full run until development passes and an independent code review allows launch. This proposal does not yet constitute the missing frozen full registration.

Fixed capacity is the complete eligible synaptic mask, not a growing store. Test naive T0; after 8,16,32 A boards; after 8,16,32 B boards. Learning remains enabled on the whole mask throughout B. At each update record every changed edge and signed gain change, clipping/floor occupancy, repeated writes, A/B co-eligible edges, A-only edges affected by B, memory bytes and total updates. Define an operational overwrite as a previously A-changed edge changed again during B; report those counts and full local state deltas. This is not a proof that every such write destroys an association. Report actual lost A margins separately.

For a pressure test to count, B must change at least 25% of A-changed edges and at least 25% of the whole mask must have changed by T_AB. These are prospective engineering stress thresholds, not biological capacity estimates. Failure to exert this pressure means P2 is untested. No claim of lifetime retention or an absolute bit capacity follows.

## 7. Arms and gates, all seeds required

Primary fly connections/informative-local-APL; learning-off-local-APL; absent-local-APL; matched-shuffled-local-APL; informative-original-global-APL (mechanism ablation). Raw Eyes keys and fixed seeded random-feature keys with the disclosed v8-style external store are labeled comparisons only; the v8-style store is also a recall ceiling, never part of primary inference. Use the same fixed experience tape for all comparisons and record actual events. Random-legal and random-capture policies are reported to expose capture-versus-quiet shortcuts.

P1 gate: all lasting primary changes are exactly on the registered existing fly edge mask; every accepted update has rechecked board/history/action/criterion/certificate binding, measured mapped-DAN response and independently reproduced local equation; all other parameter/sign/topology/input/decoder hashes unchanged. Unknown event count is explicit. No store/lookup in the primary arm. Fresh-process checkpoint reconstruction must reproduce all primary scores and complete persistent fingerprints.

P2 margin: on A boards define `m=mean(score of all certified safe captures)-max(score of all other legal moves)`. Let `dA=mean(m_A_afterA-m_A_naive)` and `rA=mean(m_A_afterAB-m_A_naive)/dA`. Require `dA>1e-6`, `rA>=0.70`, positive B margin acquisition from T_A to T_AB by >1e-6, and A/B s/c success improvement over their respective prelearning checkpoints. Both A and B must exceed learning-off and shuffled controls, with positive game-clustered paired-bootstrap lower bounds. A zero or negative learned denominator fails, never vacuously passes. Report every board margin, losses and each load level. Capacity-pressure thresholds above must pass. Include a training-only correction check: the fixed originally mistaken rankings (identified at T0 without changing the tape) must improve after their certified experiences; if there are no such rankings, correction is untested, not passed.

P3 gate: after B learning, on the new test games, primary s/c success exceeds learning-off and shuffled, for each seed and each A/B test group, with a game-clustered paired-bootstrap 2.5th-percentile lower bound >0 (10,000 resamples, fixed RNG seeds written in the registration). Also require primary to beat random-capture in this narrow task, to prevent a capture/quiet shortcut from being described as safe-capture learning. Report raw/random-feature arms whether better or worse; primary need not beat an engineered ceiling. Report both aggregate and separate A/B scores. No bootstrap over independent boards when multiple boards share a game; no pooling seeds to repair a failing seed.

Mechanism claim: local APL must improve retention relative to original-global-APL without failing acquisition/correction. If P1-P3 pass under both, the synaptic result is reported but the stabilising explanation remains unestablished. If only a changed baseline preference or overall silencing supplies the apparent gain, reject the causal stabilisation claim. Publish activity distributions, zero/saturation counts, pairwise KC overlap and harmful repeated-write summaries. No geometry sensitivity arm replaces the registered primary.

Completion requires one registered full run with every P1-P3 gate passing in every seed and independent audit PASS pinned to its actual transitive source/data/protocol/registration hashes. A development pass is not goal completion. All reports lead with limits and compare the handoff line by line; no reasoning or living-fly claim follows.
