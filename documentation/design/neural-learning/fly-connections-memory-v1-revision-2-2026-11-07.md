## 1. Remove the rejected teaching computation

There is **no cue-only/cue-plus-DAN subtraction, counterfactual neural trial, retained earlier-cue eligibility, teacher-enabled learning gate, or omission-specific D=0 branch** in the primary arm. This removes the need for a biological mechanism that distinguishes dopamine by its cause.

Use the cited Gkanias gamma4 discharging branch's **PAM07** population, not PAM08. The publisher's neuron table names MB312B / PAM-gamma4<gamma1gamma2 / PAM-07; the pinned ontology's `FBbt:00111019` distinguishes this from PAM08 (`FBbt:00111020`). Both identities, all retained roots and receiving-side gamma-KC-to-MBON05 masks must be published and independently verified before graph use. Do not rename all gamma4 DANs PAM07 or claim PAM08 equivalence. No sign overlay or population chosen from chess scores.

For each training presentation, run the cue with the scheduled experimental teaching current (positive +0.75 per mapped PAM07 cell, or zero current). From its **single actual endpoint** use `k_e=h[KC_e]/1.5` and `D_group=-mean(h[PAM07_group])/1.5`. No baseline subtraction is used: the source's nonnegative activity variables are represented by the actual nonnegative model rates, with one declared scale. Apply the existing theoretical branch `g_next=clip(g+0.5*D_group*(k_e+g-1),0.2,1.8)` once per presentation. Preserve the original Euler bound `0.5*(-D_group)<=1`; if violated, fail before mutation rather than adapt the step to the example. The original gain setter preserves the released fast sign. The zero-reference array, if the existing class is reused, is identically zero and carries no information from another experience.

This is a simultaneous, quasi-steady computational adaptation of a published theoretical rule. It is not a replication of the full Incentive Circuit, measured receptor kinetics, dopamine release concentration or biological time. It introduces no memory of an alternate neural trajectory. Transient rates are actual circuit outputs; the positive experimental current is delivered to identified neurons. Only registered synaptic gains persist. The decoder is the fixed source-motivated negative MBON05 rate; behavior, fast transmitter sign and teaching polarity remain distinct. Preserve and disclose both hemispheres' graph-sign provenance.

**Endogenous dopamine is retained.** Every scheduled presentation in informative, absent, shuffled and mechanism-control arms invokes the local rule using that arm's actual neural endpoint, whether or not an external pulse was supplied. Therefore absent means **no external teaching**, not no synaptic change. The learning-off arm is the exact no-update floor. This directly addresses the v1 control mistake through the correct estimand: informative must improve from its own naive state and beat both absent and learning-off; no claim that sensory DAN activity vanished. If sensory activity saturates the teaching pathway or makes all arms equivalent, that is a failed mechanism result; do not subtract it away afterward.

No negative current, negative dopamine concentration, arbitrary punishment channel or positive dopaminergic factor is introduced. Positive task outcomes evoke the source-matched rewarding-population current. Other known outcomes have no externally delivered pulse, but remain actual modeled sensory/neuronal experiences. Unknown verification produces no scheduled teaching experience; log it separately. In a balanced tape, the shuffled arm receives the same pulse count, presented through the same mapped neurons at permuted known events. Independent audit records measured DAN responses, not just requested pulses.

## 2. Specify the APL recurrence and strength control

Keep the first draft's roots, existing retained contact masks, per-contact division of each KC-to-APL aggregate magnitude, tree kernel, length scale and fixed signs. For each APL output contact y and neural step t:

`u_y[t] = model.drive[APL] + sum(nonKC i -> APL, signedMagnitude_i * h_i[t]) + sum(KC contacts x, magnitude_edge(x)/count_edge(x) * h_KC(x)[t] * K(x,y))`.

`a_y[t+1]=(1-alpha_APL)*a_y[t]+alpha_APL*relu_tanh(u_y[t], model.saturation)`.

Here `alpha_APL` and `relu_tanh` are exactly the unchanged simulator's leak and activation. Initialize every a_y[0]=0 for every candidate. The original whole-cell APL state remains for its non-KC outputs. In the recurrence for a KC at step t, subtract each original `signedMagnitude(APL->KC)*h_APL[t]` contribution exactly once and insert that signed magnitude times the mean a_y[t] on that ordered pair's output contacts. Local state at t+1 never feeds the KC's step t. No double count, extra edge or persistent local field.

An explicit **global kernel mode K=1**, not numeric Infinity passed into the existing prototype, must reproduce the ordinary scalar APL path on independent small fixtures, including non-KC input and external drive. Both use the same arrays/rounding and original initialization where exact equality is possible; otherwise freeze a justified numerical tolerance before graph use. Nonfinite inputs and missing pair contacts fail.

Add **informative / strength-matched-nonlocal-APL**. It computes the same local field from its actual neural state, then substitutes one uniform value for all APL-to-KC outputs: `U[t]=sum_e(magnitude_e*mean_y(a_y[t]))/sum_e(magnitude_e)`, separately per APL cell. Thus, for that exact presynaptic state, total outgoing inhibitory current equals its local field's total, but the spatial distribution is removed. Across diverging arms, total trajectories need not be identical; disclose that conditional matching. This is an engineered causal control, not source physiology. Original-global-APL remains a separate diagnostic ablation. Computational costs of the local-field and strength-matched paths are matched.

Local APL is **a candidate stabiliser**, not a demonstrated stabiliser or a necessarily stronger decorrelator. Separate three conclusions: P1-P3 joint success; locality's causal contribution relative to strength-matched nonlocal output; and biological fidelity. A joint memory pass does not require falsely attributing its cause to APL if other conditions pass too. No added APL-superiority gate redefines the researcher's P1-P3 requirement.

Geometry alternatives remain finite stress cases, never uncertainty bounds or proof of exact attachment. Define distinct alternative branches by maximal skeleton chains whose internal vertices have degree two; for the alternate projection choose the closest segment on a different chain within 100 nm of the best residual, with stable segment-ID ties. Report all cases, including those with no alternate. The complete canonical sample's known APL-side substitution is another finite stress condition. Do not infer unseen branch correctness from passing them. Freeze the primary midpoint condition and report geometry dependence; no winner substitution.

## 3. Make the experience budget explicit and the seeds real

Replace the first draft's all-actions x four-epochs tape. Before neural data, the teacher independently verifies the complete legal action set on each training board, selects two safe and two unsafe non-king capture experiences in a fixed SHA-256 order (cycling if only one of a class exists), and schedules these **four training events per board, one pass**. This is a disclosed enriched teaching curriculum. It is fixed from training-only certificate results, not neural scores. It supplies both kinds of verified experience and does not filter the learner's ranked move list: **every ranking before every event still contains every legal move**, including all quiet and king actions. The fly sees no marker identifying the teacher-selected subset. It is a fixed-experience assay, not self-chosen exploration or a test of arbitrary natural game distributions.

For each seed, independently permute the 32 A boards, the 32 B boards and the four scheduled actions within a board; preserve the A-before-B phase order. All arms in that seed consume the **same realized board/action tape**. All use the same naive graph parameters; the seed genuinely varies experience order, rather than unused input/head arrays. Save the permutation/PRNG identity, seeds and whole tape hash before propagation. No best-order selection. Shuffled reinforcement is a separate seeded permutation within the corresponding complete A/B/R phase and retains exact pulse counts.

One event: rank all legal candidates from the unchanged snapshot; save the complete ranking and state fingerprint; verify the selected action's exact certificate; replay that selected cue with the scheduled external current; read the actual endpoint; compute one local update; publish the pending receipt and next checkpoint before acknowledgment. In a no-current event this last replay still occurs with zero experimental current. All arms have the same numbers of observation/replay passes. Evaluation never advances learning or transient/persistent teaching clocks.

Let L(b) be the complete legal count of board b. The training pass count per arm/seed is exactly `sum_b 4*(L(b)+1)`, plus registered probes, correction phase and restore/audit checks. If candidate-order invariance reruns every ranking, count its second L(b) too; it is not a free check. Freeze all probes and their counts in registration. Source geometry compilation has a separate registered offline budget and no neural learning.

The earlier 24/72-hour durations are **not verified runtime estimates**. A detached dry run pairs informative teaching with controls and provides bounded actual measurements of the implemented path. Before full launch, derive exact pass counts from the frozen tape and combine them with its measured pass/resource costs and declared headroom; either register a justified wall/pass budget or reject the workload. Do not run a separate untrained graph benchmark when the informative dry run can supply that measurement. No silent extension or unchanged-budget retry after a guard failure.

## 4. Acquisition, retention and pressure

Preserve the researcher's **0.70** margin-retention bar, the after-A and after-B checkpoints, all-seed requirement, finite fixed synapse mask and every-overwrite report. Replace the first draft's margin by the actual choice margin `m_b=max(score of safe non-king captures)-max(score of all other legal actions)`. This measures choosing any criterion-successful move. The all-legal s/c measure still handles top ties. Positive naive preference is not counted as newly acquired memory without improvement.

At T_A, an A board is acquired only if its all-legal success probability >=0.75, its choice margin > the frozen score tie tolerance, and its margin exceeds its own T0 margin by >1e-6. Require at least 24/32 A boards acquired; record every unacquired board as a failure, not an exclusion from the report. The acquired set is determined on **training evidence only**, never test evidence.

After B, require every acquired A board to remain successful (s/c >=0.75) and retain `(m_AB-m_0)/(m_A-m_0)>=0.70`. Also retain the full original group-level learned-margin ratio >=0.70 over all 32 A boards with a strictly positive denominator, so redefining an acquired subset cannot hide group loss. Publish all per-board ratios, raw margins, final choices and all lost memories. B acquisition requires >=24/32 B boards meeting the same success/absolute-margin/improvement criteria relative to **T_B0, immediately after R acquisition and before B learning**. Primary A/B success must improve from its own corresponding prelearning checkpoint and beat absent, learning-off and shuffled; compute game-clustered bootstrap bounds, report each seed separately. T_A remains A's post-acquisition reference; R presentations must not be hidden when defining B's baseline.

An overwrite record contains the edge's previous and new gain **and the actually applied Float32 magnitude bits/values**. Repeated A-to-B writes count toward the operational pressure threshold only if they change effective bits and the effective magnitude by at least 1% of that edge's naive magnitude. Require such B writes on >=25% of A-written edges, and >=25% of the complete mask to have effective changes of that size by T_AB. Report all smaller/tail changes separately. These are numerical stress thresholds, not an estimate of biological bits/maximum associations. Distinguish shared-state competition, saturation and actual behavioral memory loss. A touched-edge total alone cannot establish meaningful pressure.

Use the same memory budget at every load; no association slots, edge allocation by task ID or growing learned storage. Source/readout/representation/weights remain otherwise fixed. Report growth of losses and effective writes at loads 8,16,32 in each group. Interpret a pass only for this measured pressure range; do not claim unlimited capacity or zero overwriting.

## 5. Test correction of an acquired preference honestly

Add four **explicit experimental reward-contingency probes R**, with source games/boards disjoint from A, B and final-test sets. This is an association/reversal mechanism prerequisite inside the same registered campaign, not a claim that a true chess safety certificate changed. Every R action is legal and fully ranked against all legal moves. Before neural observation choose two distinct target legal actions by a fixed hash order. Their targets are opaque to the fly; only experimental stimulation conveys the outcome.

R phase 1, after learning A: four cycles of both target actions per R board, with a positive teaching pulse for the first target and no external pulse for the other. Require each R board's first target to have s/c >=0.75 and positive choice margin against all other legal actions, improved from its pre-R checkpoint. At T_AB, before reversal, require that acquired first target still meets this successful-preference condition; losing it during B is not successful correction. R phase 2, after B and before final freezing: exchange these **declared artificial reward contingencies**, with the same four-cycle/two-action exposure. Require each board's second target to achieve s/c >=0.75 and a positive margin, and the formerly acquired target to cease being the sole preferred action. A mere margin increase that leaves the old choice dominant fails correction.

An R certificate binds full board/history, UCI action, experimental-contingency criterion version, planned phase and intended delivered current; the independent auditor checks legal replay and exact predeclared contingent stimulation. It never calls these records safe/unsafe chess consequences. Their neural response/update receipts use the same source-matched pathway and local rule as A/B. All controls share the R experience tape and count/timing; shuffled reinforcement preserves each R phase's pulse count. No label/phase ID is an input to the fly or a selector for different synapses.

After R acquisition and after R reversal, re-test A and B. The acquired A retention and B success gates must remain satisfied; correction that erases unrelated acquired A memories fails the joint result. No artificial R success substitutes for chess A/B acquisition or P3. If R cannot be justified as a source-bounded prerequisite within this goal, reject this definition before build rather than mislabel the reversed outcomes.
