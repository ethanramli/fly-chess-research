# Fixed-budget sequence replay

2026-10-07. This proposal turns one verified avoidable root miss into a small, fixed number of immediate board/action replays from the certified line. It is intended to test whether explicit feedback on earlier attacker choices helps more than reviewing only root candidates. It does not teach the fly to calculate farther, create a neural eligibility trace, or establish reasoning.

The standalone planner is [verified-sequence-feedback.mjs](../../../.codebase/src/search-and-feedback/verified-sequence-feedback.mjs). It accepts a reviewed plan only when the committed move is a checked failure, a checked successful alternative exists, and the review marks the miss avoidable. It replays up to four certificate clips per branch, each bound to the exact board history, actor and remaining horizon. Unknown or inconsistent proof results cannot produce an added replay.

The default schedule has four neural experience slots. It retains the committed root failure and successful counterfactual, then selects up to two earlier attacker decisions: one verified failure and one verified success when both exist. These occupy slots that otherwise would have been used for other root counterfactuals. The receipt records root experiences displaced by the schedule and any checked sequence clips left unused. It does not increase neural event count. If no qualifying contrast or no later attacker decisions exist, the original plan is returned without sequence replays.

This schedule is an explicit teacher choice after verification. At each replay, the existing learner receives that board/action cue and its independently checked binary consequence through the existing feedback interface. The event does not tell the learner that the intermediate move caused the final outcome, parse a line explanation, or update memories for hypothetical positions that were not replayed. It offers separate examples along one illustrative branch; alternate successful branches and causal necessity are not inferred.

## Evidence and limits

Two software tests cover a composed mate fixture and guard/unknown cases. The fixture confirms that the fixed four-event budget retains the committed failure and success, selects the earlier `f7f6` failure and `h5h7#` success, independently rechecks each added certificate, and records two displaced root reviews. This validates planner behavior only. No connectome inference, feedback update, retention, learning, latency or transfer test has run.

Before graph use, freeze a new protocol and source archive. Compare root-only and sequence-replay schedules from identical starting memories with the same total neural presentations, verified target family, candidate-review budget, and absent, matched-shuffled and disabled-plasticity controls. Match or explicitly measure teacher proof work, since sequence clips incur additional verification. Record every candidate ranking before and after events; evaluate unaided and under the same frozen search budget. Require a preregistered unfamiliar-family and counterfactual gate. Any successful fixture repair would still be narrower than transferable reasoning.

This is a later integration candidate, not the next minimal-transfer gate. The current capture-retention result points to a relation-to-activity-to-choice problem; immediate sequence clips are not required to test that bridge and could add another confound. First establish whether the frozen relational input can drive a learned, counterfactual-sensitive choice under matched controls. Revisit sequence replay only when testing the broader Monte Carlo consequence-learning loop.

The root-only and sequence conditions must not share final families. Preserve all earlier capture-retention, stability, smothered-acquisition and transfer failures. This proposal does not override the full objective: useful consequence-sensitive learning across unfamiliar positions, with improved decisions per experience.
