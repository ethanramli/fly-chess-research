# Smallest credible consequence-transfer milestone

2026-10-07 researcher steering: stop cycling through repetitions and methods without a causal design. Seek a small learned relationship reused in a different situation. This is a prerequisite to the original puzzle-investigation goal, not a replacement for disjoint-family reasoning, broader chess ability or the full goal. No new training or graph diagnostic is authorized by this document alone as an automatic next step; finish the design first. The already-running read-only dose evaluation may finish and be audited.

## Diagnosis from current code

The current system can learn board/action preferences. The existing relational encoder already normalizes actor direction and some file reflections, so adding a generically named relational encoder again would repeat prior work. It hashes candidate-relative geometry tokens into a limited KC stimulation set; the current experiment uses14 cells. Token overlap is not evidence that a useful relational variable is preserved in evoked neural activity.

In `mapped-puzzle-brain.mjs`, `evaluate` supplies move priors but returns position `value: 0`. This specifically prevents learned position values from influencing search backups; it does not prove that all reasoning or transfer is impossible through a policy. In `dual-valence-puzzle-brain.mjs`, `replay` verifies an experience, encodes the original board/action and supplies a teaching channel. Recorded line explanations are not encoded into a transition sequence. The local rule samples endpoint KC/DAN excess activity. There is no validated long-delay credit mechanism or learned consequence output.

These are architectural facts. They do not establish a single proven cause of failed transfer. Prior audited joint familiar repair and failed sibling/dose results show that persistent preference learning alone has not met the goal. No-feedback exposures can themselves drive the modeled local update; that drift must be measured alongside informative effects.

## Concrete proposed first relationship

Use a bounded capture-and-recapture microtask: learn whether a candidate captures a piece while preserving the capturing piece through the opponent's next legal reply. This avoids asking the learner to discover general chess value, mating strategy and delayed sacrifice credit simultaneously. It is a task-specific consequence, not a general definition of a good chess move.

Training examples vary the nuisance context and contain both outcomes. A geometrically tempting capture can fail because of a legal recapture; a similar-looking capture can succeed when the relevant line is blocked or defender displaced. Independently enumerate the bounded opponent replies for teaching only. An unresolved verification supplies no event. The teacher delivers verified experience and consequence, never parameter deltas.

Held-out cases must change piece arrangements and distracting context beyond the encoder's built-in mirror/colour equivalences. Include paired counterfactuals that change the recapture possibility while retaining surface similarity. Do not reuse inspected smothered-mate siblings as final evidence. Balance capture identity, mover type, location, material, check status and side wherever feasible so an isolated cue cannot predict the label. A preliminary two-choice assay isolates the mechanism; subsequent all-legal integration remains a separate required gate.

## Required computational bridge before implementation

1. **Define the learned output:** a fixed neural readout for this bounded consequence preference, with polarity frozen before testing. Do not call the current MBON score a calibrated probability or position value. Do not fit a supervised decoder.
2. **Preserve the relevant relation:** specify bounded piece/role/geometry inputs and how they reach existing mapped neurons. Public relationships may be engineered inputs, but explicitly count that as supplied structure. Exclude safe/unsafe flags, legal-recapture labels, mate indicators, proof text, Stockfish evaluation and test-outcome-derived features. Any input that computes the target already invalidates this assay as learned consequence evidence.
3. **Specify what is learned:** a shared response to the relation must be updated by the existing local mechanism and reused across examples. Verify that nuisance changes preserve useful input information and that counterfactual changes are distinguishable. Exact cue invariance alone is engineered equivalence, not learned transfer. Do not silently assume that arbitrary hash overlap implements variable binding or relational composition.
4. **Fix credit timing:** begin with an explicitly bounded immediate candidate/consequence association. If before/action/after/reply sequences are introduced, declare the short-time neural state and credit mechanism, justify it biologically and test it independently. Do not claim that current endpoint replay already learns a transition model or long calculation.
5. **Specify the discriminating evidence:** trained frozen memory improves unfamiliar choices over the same initial, absent, shuffled and disabled controls; choices reverse appropriately in counterfactuals; reset removes the acquired advantage and restoration recovers it. No learning, teacher ranking or external best-move selection at evaluation. Use multiple independent cases and seeds with a predefined primary comparison and uncertainty report. One lucky move is insufficient.

The deliverable before another training run is a complete input-to-local-memory-to-output account and a frozen small assay that can reject it. If representation alone solves the assay before learning, it is engineering evidence. If acquisition fails, the interface/rule is not established and transfer testing cannot repair it. If acquisition passes but relation-preserving cases fail, diagnose representation and shared readout. If both positive and negative counterfactuals receive the same answer, diagnose shortcut/generalization rather than scaling repetitions.

Passing would support **narrow learned consequence transfer**, consistent with an elementary component of reasoning. It would not establish general reasoning, chess strength, living-fly reasoning, or automatic acceleration of later learning. The idea that subsequent progress becomes hyperbolic is an untested hypothesis; measure learning efficiency on a later task separately.
