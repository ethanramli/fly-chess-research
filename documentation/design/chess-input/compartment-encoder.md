## Implemented factors, neural results pending

[New encoder](../../../.codebase/src/chess-input/compartment-chess-cue.mjs) wraps the preserved relational V2 feature inventory. Four conditions separate two changes:

1. Original features and pooled projection: physical stimuli reproduce the existing encoder exactly.
2. Candidate conjunctions and pooled projection: every relational feature is paired with the public candidate's piece/displacement/promotion action token. This retains reusable geometry rather than introducing a whole-position identifier, solution or verified consequence.
3. Original features and balanced eligible-pool projection: select seven unique cells from PAM02-eligible projections, then seven additional unique cells from PPL103-eligible projections.
4. Candidate conjunctions and balanced projection: both changes together.

Selection uses fixed seeded hashes and per-cell budget ordering, without response/feedback-dependent selection. Overlapping pools can yield more than seven directly eligible cells for a compartment; record both membership counts. PAM-first ordering is an explicit engineering convention, not a biological prediction. All selected cells remain existing mapped KCs. If projected features cannot supply the fixed number of unique cells, fail explicitly rather than pad with arbitrary neurons.

Keep physical dose matched at 14 distinct cells, current 1.5 each and total 21. Fixed signs/wiring, plasticity equation, numerical steps, readout and reinforcement populations stay unchanged. Both factors must be compared separately before assigning an improvement to conjunction versus compartment access. The wrapper's identity includes mapping, factors, seed and quotas; the original encoder and all frozen experiments remain untouched.

The prior source evidence for sparse-code overlap and compartment-dependent plasticity is summarized in [the myelination/plasticity note](../../../research/literature/myelination-and-learning.md), including [Hige et al., 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4674068/). That primary experiment does not support this exact hashing, chess representation, seven-cell quota or PAM-first selection. These are assistant engineering choices, related to the researcher's proposed board-action conjunction hypothesis. No new externally sourced biological solution is installed.
