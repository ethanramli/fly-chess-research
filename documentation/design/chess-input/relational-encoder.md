# Relational encoder: candidate-relative board features

2026-10-06. New experimental encoder, alongside the unchanged absolute encoder. [Frozen read-only panel](../../../research/data/relational-cue-panel-v1/protocol.json) completed and audited; no learning condition enabled.

The original goal is reasoning through investigation and verified consequences, with persistent improvement on unfamiliar/counterfactual positions. A representation tied to absolute squares can obscure reusable relationships. The new interface describes each piece relative to a candidate's origin and target, with self/opponent roles, moving piece and displacement. Origin features are conjoined with the action vector. Edge distances remain visible because translating a mating net away from a board edge can change its consequence. Capture type, promotion, castling rights, en passant, repetition and halfmove context are public inputs. No attack evaluation, future move, mate query, proof, reward or dataset ID enters the encoder.

Actor/rank normalization treats colour-exchanged positions consistently. File reflection uses a canonical token inventory only when neither side has castling rights; reflection is not assumed to preserve castling. Neither normalization establishes learned transfer: those equivalences are engineered before training. An actual changed king-support position has a different cue and makes the formerly mating move fail. The panel verifies this outcome only after model input evaluation.

Features project through a frozen SHA-256 hash onto the same mapped KC pool. Neuron identity, graph, signs and model parameters stay fixed. This remains direct experimental KC stimulation; no natural sensory interface is claimed. Seed 14009 is frozen in both old/new conditions, with the same 64-cell/24-current/1.5-per-cell limits. Cell counts and actual amplitudes can differ; report them rather than claiming a matched neural dose. No decoder fitting, gate tuning, source learner modification or dependencies.

The panel measures every legal candidate at the original, file-reflected, colour/rank-exchanged and king-support-counterfactual fixtures, with exact repeats. Compare cue collisions, overlap, distinct neural scores and naive rankings. All transformed candidates must have exact relational cues/responses; the counterfactual must differ. These are engineering fixtures, not held-out families selected to claim reasoning.

## Does the fly see the board through its eyes?

No. Both current encoders read a structured chess.js board and candidate, then directly stimulate mapped Kenyon cells. They do not render an image or model retinal transduction/visual transmission. The full connectome's presence does not establish that this path is active or that vision has been reconstructed. A future eyes-based condition would require a rendered scene, justified retinal dynamics, verified input-neuron identities and propagation through visual circuits, with independent perception and task checks. No such implementation or validation exists here. Keep the symbolic-input limitation explicit in any reasoning claim.

After input checks, a fresh frozen neural-learning comparison must establish association/reversal and useful full-root choices with matched controls before unfamiliar-family conclusions. Relational features may still alias, interfere or support memorization. Richer consequence feedback, delayed credit, multi-ply investigation and broader adaptation remain unresolved.

## Completed evidence and limits

[Raw results and exact commands](../../../research/reports/relational-cue-panel-v1-2026-10-06/README.md): 214 read-only presentations, 52 exact transformed candidate pairs, four independently checked outcome contrasts, eight exact repeats and a one-candidate resumed prefix audit. All candidates have distinct cues/scores within each board. Original-board mean cell Jaccard is 0.51614 absolute versus 0.28335 relational. However relational stimulates 14–15 cells at total current 21–22.5, versus absolute 16–17 at 24, so this is not a matched-dose learning result. Fifty-five tests pass. Main: 115.44 MiB RSS, 119.482 elapsed seconds, 57.452 CPU seconds, heap 256/duty 0.5.

For the next experiment, explicitly match count/amplitude rather than just caps; a 14-cell cap is a proposed engineering comparison that would give 14 at 1.5 for every input in this panel. New inputs still require verification. Colour symmetry with nonzero castling rights has not passed: V1 changes case without canonical reordering of the castling string, so equivalent colour exchanges can differ there. Correct that in a separate version before broader use; preserve the pinned V1 evidence. Exact symmetry cues are engineered invariance, not unfamiliar learned reasoning.
