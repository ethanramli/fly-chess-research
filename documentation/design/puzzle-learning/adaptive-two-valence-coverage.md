# Two-valence adaptive feedback coverage

Prepared 2026-10-06. This is a new diagnostic experiment, not a reinterpretation of earlier failed gates. Teacher review, resumable orchestration and the full-graph entry point are implemented. Original-input read-only preflight passes. Independent audit and final protocol/source freeze remain unfinished. No new neural run has started.

## Question and fixed boundary

The four-input comparison failed acquired improvement with a common short teaching schedule. Previously tested punishment-only adaptive review also failed. Neither establishes whether reviewing the currently preferred action with both existing reinforcement channels can repair all-legal ranking. Keep the existing local efficacy rule, graph, model, readout, reinforcement mapping and fixed input dose unchanged. No new negative update, decoder fitting or physiological mechanism is proposed.

Evaluate all four existing input variants rather than selecting one from these fixture results. These are reused training fixtures, not independent confirmation or transfer data. Freeze the protocol and source identities before any new learning invocation.

## Proposed orchestration

1. Record naive choices for both fixtures before any feedback. Keep this whole-panel baseline separate from sequential before-fixture measurements: earlier learning may create an error on a later fixture, and fixing that error alone is not acquisition beyond the naive model.
2. For each variant, run adaptive informative feedback first, with eight review attempts per fixture. After each update, score every legal move and commit to the highest fixed MBON preference. Verify that committed action independently; replay its checked board/action context through the existing two-valence receiver. Stop at the fixed attempt budget even if a fixture becomes correct. Unknown verification consumes an attempt and supplies no neural teaching event.
3. Replay the exact adaptive experience sequence into absent, valence-shuffled and disabled-plasticity controls. Freeze the shuffle seed before learning and preserve known-event channel counts. If the sequence contains only one valence, report the shuffled comparison as uninformative and fail its specificity gate. Do not add successful teacher actions just to make this control pass.
4. Add a fixed-schedule condition at the same sixteen total attempts, repeating each fixture's four archived checked experiences twice. This comparison tests adaptive coverage against fixed exposure at the same budget; it is separate from causal controls matched to the adaptive sequence.
5. Measure the whole fixture panel again after all learning, with memory frozen. Record all candidate scores after every attempt to distinguish persistent repair, initial preference advantages and interference. Measure unaided and fixed-budget Monte Carlo choices separately. External search does not count as neural choice repair.
6. Persist memory and pending receipt before acknowledging any update. Resume pending receipts without repeated stimulation. Stream event and ranking artifacts with hashes; checkpoints retain only bounded references and currently needed state. Audit channel counts, certificates, local recurrence, graph invariants and recovery independently.

Keep graph invocations serial, the existing 768 MiB RSS/256 MiB free-memory guards, 256 MiB Node heap option and 0.5 duty pacing. Bound all-legal candidates, presentations, attempts, verification and Monte Carlo state explicitly. Larger budgets increase elapsed time rather than batch memory.

## Proposed acceptance

Require both final informative unaided choices to be verified successes; at least one fixture must improve from the whole-panel naive failure while its matched absent and disabled controls remain failing. Require an informative, nondegenerate shuffled comparison, exact learned-state repetition/restoration and naive reset, and independent receipt/recovery audits. Report the fixed-schedule result whether it succeeds or fails. These exploratory single-seed familiar-fixture gates cannot establish statistical generalization, biology or reasoning. Any apparent repair needs separately frozen fresh confirmation and unfamiliar/counterfactual consequence-sensitive evaluation.

## Implemented teacher component

Unknown outcomes have no pulse, certificate or explanation. The teacher computes no neural updates and never selects an alternative on the brain's behalf. The existing receiver must recheck the event at delivery, including after resume.

## Corrected full-graph result

The original-input v2 run completed all 80 attempts (five conditions, two fixtures, eight attempts per fixture) and passed the independent audit. The runner and auditor agree on all exploratory gates: both informative final choices are successful; at least one naive failure is repaired while absent and disabled controls remain failing; the seeded shuffled condition is nondegenerate and fails its matched repair comparison; persistence/reset/restoration and fixed-state checks pass. The independent audit checked 228 certificates, 64 enabled local updates, all-legal rankings, cue projection, matched schedules and local recurrence. Resources were 126.18 MiB peak RSS, 1,770.78 seconds elapsed, 868.41 seconds CPU and 3,504 presentations. This is computational evidence that this particular two-valence schedule can repair familiar fixture choices under matched controls. It is not evidence of unfamiliar/counterfactual transfer, biological validity, natural visual perception, strategic evaluation or reasoning.
