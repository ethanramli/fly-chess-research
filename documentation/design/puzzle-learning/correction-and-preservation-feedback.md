## Bounded lesson selection

Use only the current training-family unaided rankings. First recheck both candidate certificates for each eligible panel. Unknown/incomplete evidence excludes the panel from teaching without counting it as a failure. Rank incorrect panels by their verified success-minus-failure margin, with deterministic panel-ID ties. Select the most confidently incorrect eligible panel as the repair target. Select the least-confident correct eligible training panel as a preservation sentinel. This targeting is a declared hypothesis; confidence is not calibrated probability and hard cases may be unlearnable.

The fixed four-event lesson reviews: the target's currently preferred verified failure, its verified success, the sentinel's verified success, and its verified failure. All are separately checked experiences. A sentinel is an additional experience, not evidence of biological consolidation or a teacher-generated neural correction. Use fresh ranking/memory binding before each delivered event. Explanations/transitions remain teacher-side records unless an independently validated neural input mechanism is introduced.

Preserve the four-slot budget. If a valid target or sentinel is absent, return an explicit unready result with no improvised punishment or fabricated reward. The graph runner must checkpoint such a stop. Selection records all eligible/unknown panels, priority, role, exact starting memory, intended exposure count and displaced uniform reviews. Controls replay the informative learner's frozen schedule; never independently choose easier schedules for controls. A matched shuffle must preserve positive/negative counts and differ from informative order.
