# Stockfish-target value learning

Prepared 2026-10-08; implementation correction 2026-10-08. Goal: learn contextual evaluation through endogenous adaptation, then measure unfamiliar consequence-sensitive transfer. This is not a claim that the current fly evaluates like Stockfish.

The learner first produces its own fixed neural value proxy, tanh((MBON12 - MBON01)/scale). Scale and polarity must be frozen before testing. The existing preference balance is not calibrated value; this transform is a falsifiable experimental interface. Its ordering and prediction accuracy must both be measured, with no fitted decoder.

The initial graded replay mixed the root action-preference score with the teacher's post-move child-position estimate. Those quantities do not describe the same state. The current isolated adapter assesses the exact child board/history with the same fixed transform, then orients that estimate from the child side-to-move to the original actor. It records root action preference separately. Its child-state proxy is `max` over the child position's action-preference values; this is still an uncalibrated engineering proxy and can be wrong. Child assessment costs additional all-legal candidate presentations; a future run must count them in compute-per-quality measures. If the move ends the game, the adapter skips before graph inference rather than inventing a terminal neural value. Post-correction tests verify child FEN/PGN, actor sign, fixed wiring, unknown targets, matched presentation counts, and zero-work terminal skips: focused suite 5/5 and full project suite 162/162. No neural graph experiment has run.

Stockfish supplies finite-budget actor-perspective WDL targets for the exact child board/history. Expected game points are (W + D/2)/1000; the signed target is twice that quantity minus one. Teacher analysis uses all legal candidates at the same two or more budgets. Budget disagreement produces an envelope, not a confidence interval. Missing, bounded or incomplete estimates are unknown and cannot teach.

Keep action regret separate from prediction error. Regret compares the chosen candidate with the best engine estimate; the graded rubric marks near-best, good, small-loss, inaccuracy, mistake and blunder. Prediction error compares the selected candidate's target with the fly's own value. A good move can still have an inaccurate prediction. See the [sources and adaptations](../../../research/literature/graded-feedback-2026-10-08/README.md).

Only a conservative signed error reaches the existing local rule: positive selects PAM02, negative selects PPL103, with current at most 1.5 and proportional to absolute error/2. The teacher never computes gain updates. Action regret and value prediction error remain separate: a valid expected-score target can teach a value residual even when the selected move is near-best and action-regret shaping would be zero. Incomplete targets still produce no event. Exact sign, channel and dose are engineering hypotheses requiring validation; they are not identified natural dopamine or a demonstrated descent direction. Drosophila evidence does not make a generic prediction-error account settled: one primary odor/shock trace-conditioning assay found no evidence for DAN prediction-error coding, while the published Incentive Circuit rule itself is reinforcement-driven rather than a direct error calculation. The Stockfish residual is therefore an explicit engineered condition, not a claim about dopamine. See the [source register](../../../research/literature/source-solution-register.md).

Implementation is isolated in `.codebase/src/search-and-feedback/stockfish-feedback-rubric.mjs` and `.codebase/src/puzzle-learning/stockfish-value-brain.mjs`. A review found a quantity mismatch in the initial `replayValue`: the teacher target described the child position after the chosen move, but the learner prediction was the root move-preference score. The adapter now records that root action preference separately, evaluates the resulting child with the same fixed MBON transform, and flips the child side-to-move estimate into the original actor's perspective before computing conservative error. Terminal or silent child positions without a neural value fail closed. The child estimate is still `max` over action preferences, an uncalibrated engineering proxy; this aligns board and actor perspective but does not make the proxy a calibrated state value. The extra child assessment also increases learner-side evaluations; measure them and include them in time-to-quality accounting. No graph run or tests were performed after this correction.

Before any graph run, add focused checks for resource-bound exhaustion and pending-receipt persistence, then implement a separate serial runner with atomic pending receipts and a fresh independent replay audit. Do not launch it by substituting code into an active pinned experiment.

## Matched task-feedback contract (2026-10-08)

Every arm must be exposed to the same independently verified task consequences, exact board/history/action, unaided pre-feedback ranking, schedule and cue. The `outcome-only` arm receives the checked task valence at the fixed bounded pulse. The `informative` arm receives that same checked task feedback plus the separately identified Stockfish value-error signal; Stockfish is an added teaching source, not a replacement for verified consequences. `no-channel` receives the same experience and neural presentations with neither signal. `shuffled` receives the same checked task feedback plus a predeclared, nonzero value-error magnitude with its sign reversed/matched to another lesson; it is not a free-form caller-selected error. `disabled` receives the informative signals at matched exposure but does not adapt persistent memory. All conditions exclude terminal-child positions in the matched value screen until a shared terminal-value treatment is specified. Unknown task proof suppresses all teaching; unavailable engine evidence suppresses only the Stockfish component, with matched-sample handling declared before training.

Focused adapter verification now covers task-certified outcome-only delivery without engine analyses, same-magnitude opposite-sign error shuffling bound to a frozen-schedule hash/event index, no-channel exposure when the fixed neural value is neutral, and an opt-in bounded trace of mapped KC/DAN rates across recurrent states. The focused suite passes 11/11 and the full project suite 168/168. These are interface tests, not a runner, independent graph audit, neural efficacy, retained learning or transfer. The runner must construct the complete matched error table before graph exposure and fail closed on unmatched missing targets. The source identities changed after repository relocation and must be freshly archived and pinned for a new protocol.

The prior failed-retention event cannot be reconstructed at full neural resolution: its receipt saved edge-aligned KC excess and group-level DAN factors, not individual DAN rates or the recurrent activity trajectory. Its recorded update affected 150/870 eligible edges, with strong negative factors in the two PPL103 groups; this is a specific candidate update path, not proof of which cells caused the choice shift. Future event traces should bind graph, mapping and memory identities in the enclosing receipt and remain diagnostic evidence, not an update target.

Before launch: pin actual engine binary/settings, sources, graph/mapping, encoder, value interface and existing memory rule; register fixed training experiences; compare outcome-only, informative value teaching, no-channel, matched signed-error shuffle and disabled plasticity at matched exposure. Check acquisition, reset/restoration, persistence and pending-receipt recovery. Checkpoints must improve per-criterion validation error and useful choices, without worsening another required criterion. Freeze selection before disjoint and counterfactual final evaluation; run unaided and equal-search-budget conditions separately.

Piece activity is contextual. Do not supply hand-assigned dynamic piece values as learned outputs. Later counterfactual probes can ask whether blocking a knight's activity or removing its support changes the learned value appropriately; an attribution is not a unique intrinsic piece price. Current scalar feedback alone may be insufficient to teach these relations.

## 27 October: set aside for Stage 1

Researcher decision: Stockfish teaching is excluded from Stage 1 and documented as a failed experiment. The absolute target opposed the verified outcome on 74 of 182 probe-v7 pulses. The all-legal regret signal rewards 19 of 28 unsafe captures. Stage 1 is outcome-only and judged on frozen D1-D8. The code, caches and D9 module are preserved.
