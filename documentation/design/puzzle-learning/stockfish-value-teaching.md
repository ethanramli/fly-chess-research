# Stockfish position-value teaching

## Researcher-authorized direction

The researcher has authorized Stockfish evaluations as an additional teaching source. The proposed loop is: the fly emits its own estimate of a position or candidate consequence; a pinned Stockfish analysis supplies a target; the discrepancy becomes a bounded experimental teaching signal; and persistent change must still arise through the simulated fly's learning mechanism. The teacher supplies a target or consequence, never a vector of neural parameter updates.

This is a promising way to provide denser calibration feedback than binary mate success/failure. It also changes the teaching condition: the study would test whether Stockfish-guided neural learning helps, alongside consequence-only feedback. Report those conditions separately. Do not claim that engine-assisted calibration alone shows the fly can discover chess concepts without engine guidance.

## What Stockfish does

Stockfish separates a **position evaluator** from **search**. Its current evaluator is an NNUE network that outputs a scalar position value used by its PVS/alpha-beta search. The current network combines sparse, king-relative piece-square features with piece-attack and pawn-pair features; its architecture is a feature transformer followed by small dense layers and one output. Inputs and accumulators are designed so a move changes only a small part of the representation, enabling fast incremental evaluation. The evaluator has learned interactions: a knight does not have one fixed positional bonus independent of king placement, activity, threats and the rest of the board.

The official training pipeline uses position datasets with Stockfish evaluation targets. It maps centipawn-like scores into a bounded win/draw/loss-style scale using an engine/data-dependent sigmoid, then minimizes prediction loss with gradient descent. It can blend score targets with game results. Validation loss helps compare checkpoints, but the Stockfish training guide also recommends playing matches because lower validation loss does not guarantee stronger play. This is conventional supervised network training; it is evidence that score-target learning is a workable engineering recipe, not evidence that the fly's local plasticity will implement it.

For FlyChess, replicate the **teacher-target concept and the separation between evaluator and search**, not Stockfish's NNUE architecture or its gradient updates. The endogenous brain, graph and allowed persistent state remain the learner. Stockfish can label a fixed set of positions or post-move consequences. The fly's own action-value output and its biological learning rule must turn that signal into retained changes.

## Deduction: when calibration should improve moves

The hypothesis is coherent: if feedback makes the fly's value estimates more accurate, then under the same legal candidates and the same search budget it should choose better moves. But a score attached only to the root board does not rank its candidate moves. To test the mechanism, the fly needs an **action-conditioned value** such as `Q_fly(s,a)` for the position after candidate `a`; the teacher supplies a matching `Q_stockfish(s,a)` under fixed analysis settings. The discrepancy can then be delivered after the action as an experimental, bounded teaching signal. The side-to-move/root-player perspective must be explicit.

This separates two possible lessons. A static NNUE score target asks the fly to approximate Stockfish's evaluator on a given position. A searched score target includes Stockfish's deeper calculation as well as its evaluator. The first is a cleaner test of evaluation learning; the second may provide stronger consequence labels but mixes evaluation with search. Keep them as separate conditions if both are pursued. In either case, compare candidate rankings with the same candidate set and search budget before claiming that improved moves came from better evaluation rather than more calculation.

For piece value, do not train a constant label such as “knight = 3” as the strategic answer. Stockfish's learned value is contextual: piece-square, king-relative geometry, attacks and pawn relations interact into an overall position score. The researcher’s examples (a passive knight versus an active one, or a rook sacrifice) are hypotheses about context-dependent contribution. A Stockfish scalar can teach which resulting positions are better; it does not by itself explain each piece's contribution. Any per-piece attribution needs its own validated diagnostic and counterfactual tests.

## Required before a graph experiment

1. **Define what the fly predicts.** The current `mean(MBON12) - mean(MBON01)` output ranks candidate actions. It is not a calibrated position score, and its units cannot be compared to Stockfish centipawns. Specify a position-value output or candidate-consequence value from identified neural activity before generating an error signal. Keep its mapping fixed during a frozen test; if the output needs supervised fitting, report that as a separate engineering comparison.
2. **Pin Stockfish's target.** Record version and binary/network hashes, score perspective, depth or node/time limit, threads, hash size, tablebase policy, and mate handling. Use a searched UCI evaluation, not the `eval` command's rough static value. Preserve the raw score and principal variation. Scores are engine- and compute-condition targets, not chess ground truth. Use one fixed score transform, declared before training; treat mate scores separately rather than as ordinary centipawns.
3. **Specify the teaching signal.** A candidate is to compare the fly prediction with the target using a predeclared error, for example `delta = target - prediction` after a fixed bounded transform. Define how sign and magnitude map to the already identified teaching pathway, how it is time-aligned to KC activity, and which eligibility trace assigns credit. Do not label this signal dopamine until its cellular identity and modeled dynamics justify that claim. The existing positive/negative pulses do not automatically implement a continuous error signal or delayed credit.
4. **Run matched conditions.** At minimum compare Stockfish-value teaching, independently verified consequence-only teaching, absent feedback, shuffled targets/signs, and disabled plasticity under the same positions, schedule and compute budget. Keep neural readout, encoder, graph and local plasticity pinned. Preserve unknown/failed engine analysis as no teaching event.
5. **Test beyond the taught boards.** Split puzzle and position families into train, validation and final test before generating targets. Measure position-score error and pairwise action ranking on held-out families, plus unaided and fixed-search-budget puzzle choices. Include support-shift counterfactuals where a similar-looking move changes value. Freeze the selected checkpoint before final testing. Same-board score fitting is not transfer or reasoning.

## Why this does not yet solve the learning bottleneck

The current multi-context run shows that verified positive/negative events can move known successful moves upward in the all-legal ranking relative to absent and disabled controls, while both final choices and both fixed-budget searches still fail. Stockfish scores could add finer teaching information, but only if the learner has an output that predicts value and the neural update connects its prediction error to the relevant active state. Otherwise the score is only more teacher data, not stronger learning.

The first bounded implementation task is therefore a readout-and-target feasibility study: determine whether a fixed neural output can produce a meaningful prediction for a board/action, define the Stockfish target under fixed settings, and test the signed error-to-teaching encoding on saved activations without changing the graph. Do not launch a full graph condition until that interface and its audit are frozen.

## 2026-10-07 relative teacher comparison and latency clarification

The researcher additionally proposes letting the fly compare its chosen move with Stockfish's move and receive feedback about the difference, while prioritizing faster iterations. Accept this as a separate teacher condition: independently analyze candidate consequences and the teacher reference under pinned settings, preserve both lines and bounds, and deliver a declared comparison signal through the endogenous pathway. The fly must make its unaided choice before seeing the teacher reference. Evaluation must hide teacher moves/targets. Do not silently substitute the teacher move as the fly's played action or train a supervised move decoder.

Full-game WDL alone can tie a short-mate success with slower wins and thus fail a puzzle deadline. Comparing two saturated WDL values may also give zero regret. Keep certified task consequences and engine targets distinct. A future comparison may need task-aware mate ordering or a separately specified score-regret transform; do not interpret a searched centipawn difference as a calibrated probability or biological error signal. This remains proposed; the record-only [target-feasibility probe](../../../research/data/stockfish-target-feasibility-v1/README.md) tests the initial target assumption first.

Teacher target caching can avoid repeated external analyses under identical binary/settings/board-history identities. Frozen-memory candidate activity may be reused only while memory, board-history, encoder and dynamics identities remain identical; a teaching update invalidates affected activity. Profile one complete puzzle round before changing graph math. Distinguish expensive verification/control/audit panels from the cost of one neural presentation and one actual learning event. Preserve matched time-to-quality, hardware guards and reasoning/transfer gates when optimizing. The prior 2,923-second multi-context invocation includes all four conditions and 3,977 presentations, not one attempted move.

## Evidence and limits

The [completed target-feasibility probe](../../../research/reports/stockfish-target-feasibility-v1-2026-10-07/README.md) contains 124 real Stockfish analyses and an independent certificate/perspective audit. Full-game WDL fails the task-discrimination gate on these two short-mate fixtures: 8 to 11 certified deadline failures tie with the successful move at maximum utility, depending on board/budget. Forty-two analyses lack a latest usable exact score. This motivates a separately frozen task-aware teacher comparison; it is not a Stockfish-learning or transfer experiment.

Retrospective analysis of the same hash-verified records found that exact mate distance adds a narrow cue: in all four board/budget panels, the verified success has actor-relative mate score `+1`, while the one exact mate-scored failure has `+3`. The remaining 74 usable failure scores are centipawn targets, so this does not rank every legal action on one calibrated scale. No neural feedback occurred. See the [mate-deadline diagnostic](../../../research/reports/stockfish-mate-deadline-diagnostic-v1-2026-10-07/README.md).

Official Stockfish documentation supports the evaluator/search distinction, sparse king-relative piece-square and interaction features, training on engine-evaluated positions, WDL score transforms, and validation plus match testing. It also says score scaling depends on the engine/data and that `eval` is only a rough static view. These support a reproducible teacher target, not absolute chess truth. Schultz, Dayan and Montague's reward-prediction account motivates testing signed prediction errors, but does not validate injecting chess-score errors into this fly-derived circuit. The particular signal, pathway mapping and credit-assignment rule here are researcher hypotheses.

## Has Stockfish made training faster?

Not yet. The Stockfish experiment recorded targets and tested whether they distinguished a verified mate-deadline success from failures. It found many failures tied with success under full-game WDL and delivered no neural feedback or training update. Stockfish is not currently improving learning direction or training time. The separate 27% cached-root workload speedup used a fixed unchanged assessment; it is an inference optimization and does not depend on Stockfish. To demonstrate Stockfish-guided training, a frozen action-consequence target and error-to-existing-pathway rule must pass matched neural learning/control gates, then improve held-out unaided and same-budget search choices per verified teaching experience.
