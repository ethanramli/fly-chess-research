# Verified temporal consequence interface

2026-10-09. [Planner](../../../.codebase/src/puzzle-learning/temporal-feedback-plan.mjs), [inert tests](../../../.codebase/tests/puzzle-learning/temporal-feedback-plan.test.mjs). A prepared experience-to-stimulus interface; it executes no neural model and supplies no parameter delta.

The planner independently rechecks a consequence certificate against exact board/history, candidate and task using the existing verifier. Claimed status, actor, teachability and certificate digest must match that verification. Unknown verification returns no frames and does not invoke the encoder. Known cases produce one cue presentation at a fixed frame, one bounded PPL103 pulse, and explicit intervening/tail frames. Favorable feedback places the pulse before the cue; adverse feedback places it with the cue. This is a declared experimental temporal code, not evidence for a natural positive-valence pathway or delayed multi-ply credit.

Cue frame, pulse lead, tail length and stimulus current must be supplied explicitly, with at most 32 frames and current at most 1.5. Frame duration is defined separately by the eventual model/memory protocol. The eight-frame schedule in software tests is an inert fixture, not a frozen graph-training schedule or a claim that its resulting waveform passes biological timing constraints.

Informative, absent, disabled, swapped and externally scheduled shuffled conditions retain the same cue timing and number of frames. Informative/disabled use verified status; swapped reverses every known label; shuffled requires an explicit scheduled status. Disabled preserves exactly the informative stimulation with learning flagged off. Absent removes the pulse while retaining the cue and frame count; it does not force endogenous DAN activity to zero. The outer scheduler must verify balanced shuffled exposure and timing; one planner call cannot establish contingency balance. Source pulse count/current is matched across feedback-bearing conditions. Actual neural input/work accounting remains the executor's responsibility.

The returned plan binds context, verified status, certificate digest, condition, teaching status, cue and complete stimuli through a digest. It contains no gain, desired score, synaptic error or learning coefficient. It does not take measured rankings, so the eventual executor must bind an unaided all-legal ranking **before** delivering any frame using the existing feedback-quality helper. Plan construction alone is not sufficient to pass the feedback quality gate.

Remaining executor work: preserve neural continuity during the sequence, advance the rate-timing memory on each declared frame, record all actual exposure, preserve pending-frame state across resource interruptions, and bind complete memory/trace snapshots to the existing resumable coordinator. Do not route this plan through the old endpoint-only replay method. No experiment command currently connects this planner to the graph; no training was run.
