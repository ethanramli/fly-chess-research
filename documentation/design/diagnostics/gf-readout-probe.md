# GF readout probe: does stored memory affect action scores?

2026-10-05. Diagnostic replay, not a new learning experiment. The [source recovery comparison](../neural-learning/recovery-comparison.md) measured an engineered MBON score. The proposed [instinct interface](../puzzle-learning/system-design.md) instead reads two GF cells. Anatomical reachability alone cannot establish a useful learned action signal. This probe measures that gap without inventing additional reward targets or changing a completed experiment.

The [specification](../../../archive/early-development/research/data/gf-memory-probe-v1/protocol.json) was saved before readout replay. It reuses all six synthetic cue seeds and all four conditions from the completed comparison. Each job restores naive, saved acquisition and saved reversal efficacy, then checks reset/restoration. All probes are read-only: no `memory.observe`, optimizer, teacher updates or new plasticity. Original MBON responses must reproduce exactly, as must reset/restoration GF values. The full graph and every nonplastic parameter remain fixed.

An experimental positive-control panel stimulates existing annotated LC4/LPLC2 cells that directly input to either mapped GF. This is not reconstructed natural looming. Calibration divides each cue's excess GF rate by that cell's panel-minus-rest range. A fixed diagnostic decoder uses the maximum of the two **unclipped** normalized rates, preferring the lower value, with exact ties choosing A. It receives no cue contingency or teacher outcome. Calibration fails when either range is nonpositive or below the frozen numerical minimum. All cells, currents, raw values and ranges are retained.

The unclipped decoder exposes small effects that application clipping could hide. It is a diagnostic choice, not the proposed application readout or a fit to behavior. Acquisition and reversal target-signed margins are compared with stored naive/acquisition responses; absent, shuffled and disabled results are retained. No gate is tuned or declared passed from these reused seeds. A new frozen, independent-seed choice experiment and biological predictions remain necessary before accepting an interface.

```powershell
node --max-old-space-size=256 .codebase/scripts/probe-gf-memory.mjs --out research/reports/gf-memory-probe-v1-2026-10-05 --cpu-duty 0.5
```

The serial driver uses one sparse model, atomic checkpoints after each complete job, the 768 MiB RSS/256 MiB free-memory guard, fixed source/input/model/calibration hashes and bounded reads of one saved checkpoint at a time. Resume with `--resume JOB_DIRECTORY/state.json` into a new output directory. `--max-jobs N` bounds further completed jobs. Resetting persistent memory for measurements is an explicit causal intervention, not a learning step or simulated forgetting.

This experiment cannot demonstrate natural reward delivery, correct subcellular masks/receptors, delayed credit, whole-model plasticity, puzzle reasoning or unfamiliar-position transfer. It diagnoses whether this particular stored efficacy candidate affects the proposed downstream action signal, including failures.

Completed [raw report and independent consistency audit](../../../archive/early-development/research/reports/gf-memory-probe-v1-2026-10-05/README.md): all 24 jobs reproduce original MBON values and exact GF reset/restoration, with fixed nonplastic/wiring identity. Informative diagnostic acquisition/reversal choices are correct in 6/6; absent and disabled controls are 3/6 in each phase, shuffled is 1/6 acquisition and 5/6 reversal. Reversal margins in all informative seeds exceed those controls, but these are descriptive reused-seed measurements, not a new acceptance gate. Crucially, **all measured baseline/acquisition/reversal GF cue responses are below rest**. The previously proposed clipped application decoder loses all differences and makes only 3/6 correct choices in each phase. This interface prediction fails even though a small causal signal exists. Do not silently substitute the diagnostic decoder or fit an outcome-dependent offset.
