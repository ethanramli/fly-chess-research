# Efficacy floor: numerical sensitivity diagnostic

Run frozen 2026-10-05; completion review and prefix replay 2026-10-06. Diagnostic numerical interventions, not training or biological bounds.

The [failed board/action association](../chess-input/board-action-association.md) did not change GF choices, and [saved-memory subset resets](memory-ablation.md) did not rescue them. This probe asks whether a fixed set of stronger, action-specific efficacy changes can change the existing decoder. The [specification](../../../research/data/chess-memory-envelope-v1/protocol.json) was saved before measuring those interventions; its masks use cue membership and optional MBON subtype, never feedback labels.

For each of six existing informative seeds, start from naive gains. Set gains on A-only or B-only KC inputs to the existing numerical floor 0.2, either across permitted compartments or restricted to MBON12/MBON01. Leave all other gains at 1. Include a naive control. Every intervention retains released identities, wiring/signs and nonplastic parameters. Gain arrays and zero event counts explicitly mark artificial, untrained states. The floor is an unfitted engineering constraint, not a measured physiological limit or a guarantee that a learning mechanism can attain these profiles.

The original GF calibration, clipped decoder and raw/signed outputs remain fixed. No stimulation of reward neurons, `memory.observe`, teacher update, search or verifier runs. All naive responses must reproduce the original baseline exactly. Each completed intervention has an atomic checkpoint; guard thresholds, 256 heap and CPU duty match other bounded runners.

[Completed raw evidence and audit](../../../research/reports/chess-memory-envelope-v1-2026-10-05/README.md): 42 profiles/84 presentations; no clipped or signed GF choice changes. Thirty-two of the 36 floor profiles select at least one edge; four MBON01 profiles have empty masks and are effectively additional naive controls. Some nonempty profiles coincide. There are small rate changes, but all profiles remain 3/6 correct against the experimental contingency. Masks, numerical readouts and a one-profile prefix replay audit correctly; 46 tests pass.

This limits control under these specific unilateral floor profiles. It does not prove that no joint gain configuration, other neural interface or supported physiology could work. Nor does it establish the cause of the failed learning rule. Do not increase the learning rate, alter signs, select a favorable decoder or turn the intervention into a teacher-computed parameter update to manufacture a pass. The original failed acceptance and the full puzzle/reasoning objective remain unchanged.
