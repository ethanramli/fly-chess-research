## One-paragraph summary

This project asks whether training a connectome-constrained fly model with an explicit chess-position evaluation method improves its move selection on previously unseen positions compared with the existing training method, when data, search, and compute are held constant. The intended contribution is a controlled test of generalization, not simply another demonstration that a fly-inspired model can play chess. The evaluation rubric, operational definition of “unseen,” baseline, and feasible experimental design still need to be specified and checked against prior work.
