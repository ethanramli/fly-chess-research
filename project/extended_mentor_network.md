## Outreach approach with timezone consideration

**Tip:** When contacting researchers across time zones:

- Email a brief, concise inquiry (1 paragraph + project link) to 2–3 researchers simultaneously across different zones.
- Wait 1–2 weeks for responses.
- Follow up after 2 weeks with a gentle reminder if no response.
- Respect that research leaders receive many inquiries; a 30% response rate is realistic.
- If someone says "not available but try X," ask for a referral and try X.

**Time zone advantage:** If you contact 3 researchers across regions (e.g., Singapore, Ohio, Tohoku), they each work in different parts of the day, so feedback can flow continuously.
